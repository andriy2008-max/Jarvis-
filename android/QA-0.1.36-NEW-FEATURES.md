# JARVIS 0.1.36 — основний чекліст нових змін (code 46)

База: стабільний 0.1.35 із повним JARVIS Finance, фінансовими командами, Bolt, Spotify та локальними таймерами **у вихідному коді**. Фізичні Pixel 9 і Galaxy Watch7 не підключені до CI. Тести збірки не підтверджують реальне керування екраном.

## Встановлення
- [ ] До оновлення експортувати/зберегти резервну копію JARVIS Finance.
- [ ] **Не видаляти попередню програму**, встановити підписаний APK 0.1.36 поверх 0.1.35 на Pixel і Watch7.
- [ ] У системі обох пристроїв версія 0.1.36 / code 46 та пакет `com.andriy.jarvis.stable`.
- [ ] На Pixel доступні старі транзакції, рахунки й нотатки; на годиннику не виникло окремого другого профілю.
- [ ] Wearable Data Layer з'єднує годинник і Pixel; голосова команда телефона доходить до Pixel.

## Watch7: НЕ закривати після відповіді
- [ ] Сказати «Скажи привіт» 10 разів — голос звучить і Джарвіс **не переходить сам** на циферблат.
- [ ] Вимкнути голосові відповіді в меню, сказати команду — текстова відповідь без закриття.
- [ ] «Увімкни реп», «Увімкни плейлист…», «Таксі до…», «Скільки часу на таймері?» — після відповідей Джарвіс залишається активним.
- [ ] Якщо системний голос Android зупинився — на обличчі відображається помилка, сеанс не зникає.
- [ ] Меню ⋮ → «🛠 Діагностика голосу Watch7» → статус TTS і код останнього збою.
- [ ] Жест «Назад» не припиняє запущений сеанс; мені ⋮ → «⏹ Завершити Джарвіса» вимагає підтвердження.
- [ ] Після кнопки Home сеанс можна повернути зі сповіщення Wear OngoingActivity. **Home може показувати циферблат** — це очікувано.
- [ ] Після перезавантаження годинника перевірити доступність сеансу; фонова служба може відновлюватися, якщо це дозволяє Wear OS.
- [ ] У режимі енергозбереження перевірити роботу з урахуванням системних обмежень. Не очікувати нескінченне освітлення дисплея або запис мікрофона після блокування.
- [ ] Локальний таймер з п. 0.1.35 працює без з'єднання з Pixel, повідомляє про завершення на годиннику.

## Spotify App Remote (офіційний SDK)
- [ ] На Pixel відкрити Джарвіс → «🎵 Spotify · прямий запуск», налаштувати Spotify Developer Client ID та авторизацію; за потреби додати redirect/SHA-1 на порталі Spotify.
- [ ] Зберегти точний Spotify URI одного плейлиста, голосовий псевдонім і один URI пісні.
- [ ] «Увімкни плейлист [псевдонім]» → починається пряме відтворення через App Remote без керування екраном.
- [ ] «Увімкни пісню [псевдонім]» → пряме відтворення збереженого URI, не пошук за координатами.
- [ ] Коли URI немає або авторизація відхилена — Джарвіс пояснює причину й переходить до безпечного старого UI-механізму.
- [ ] «Увімкни реп» збереженим плейлистом або через бібліотеку та фільтр; відтворення реально чути.
- [ ] App Remote не дублює натискання після успіху, не завершує Джарвіса на Watch7.

## Mobilerun Portal: кнопки Bolt та Spotify
- [ ] На Pixel встановити Mobilerun Portal окремо, видати доступ Accessibility і ввімкнути локальний HTTP сервер `127.0.0.1:8080`. Хмарний/reverse доступ вимкнений.
- [ ] У Джарвісі відкрити «👁 Mobilerun Portal», ввести локальний токен (не вказувати його в чаті), увімкнути Portal.
- [ ] Прочитати стан Portal через кнопку перевірки: показано правильний пакет переднього плану та число елементів.
- [ ] Bolt: «Рушаймо» й «Місце висадки» знаходяться за написами і безпечними межами, а не натискаються в іншій програмі.
- [ ] Після «Місце висадки» адреса вводиться й підтверджується Enter; **поїздка не замовляється автоматично**.
- [ ] Spotify: якщо Accessibility не бачить вкладку «Пошук» або «Моя бібліотека», Portal допомагає натиснути потрібну вкладку.
- [ ] Якщо Portal вимкнений/не встановлений — звичайні команди через вбудоване Accessibility залишаються працездатними.
- [ ] Якщо Portal бачить декілька неоднозначних елементів — Джарвіс зупиняє ризиковану дію, не натискає навмання.
- [ ] Сповіщення про кожну проміжну дію видиме на Pixel.
- [ ] Закриття або збій Portal не закриває застосунок Джарвіс на Watch7.

## Межі перевірки
GitHub Actions може перевірити збірку, підпис та Java-контракти, але не є фізичним тестом Pixel/Watch7. Watch7 не можна гарантувати невимкнення роками — Android може завершити фоновий процес або вимкнути екран, навіть якщо код не викликає `finish()`.
