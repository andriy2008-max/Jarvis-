# JARVIS 0.1.7 — голосова активація і Wear OS

## Погоджена поведінка

- Скажи «Джарвіс, розкажи…» — **ніякого** проміжного «Слухаю», команда передається одразу після розпізнавання речення.
- Скажи лише «Джарвіс» — піксельне обличчя змінює стан, відкривається 12-секундне вікно для наступної фрази; ім'я саме по собі **не викликає платний OpenAI API**.
- Після відповіді є приблизно 35 секунд, щоб продовжити розмову **без повторення імені**. Після тиші потрібне нове звертання «Джарвіс».
- «Джарвіс, досить» або «закінчи розмову» — завершує розмовний режим без голосового підтвердження.
- Кнопка мікрофона та фізична кнопка годинника (якщо її подію надає Wear OS) працюють без обов'язкового ключового слова; повторне натискання завершує запис.
- Команди керування пристроєм залишаються локальними, а довільні запитання відправляються в особистий HTTPS-посередник тільки після активації або явного натискання мікрофона.

## Обмеження та приватність

Android `SpeechRecognizer` не призначений для безкінечного wake-word-моніторингу. Реалізовано експериментальне поновлення коротких сесій **лише коли відкрито JARVIS** і тільки якщо Android надає `createOnDeviceSpeechRecognizer` (API 31+). Не обіцяємо постійний режим чи роботу в іншій програмі/із заблокованим екраном. Навіть on-device розпізнавання має обмеження щодо українського мовного пакета і витрати батареї. Коли воно недоступне, працюють кнопка мікрофона та текстові команди (можуть користуватися штатним мережевим розпізнаванням Android). Режим можна вимкнути перемикачем.

Розпізнавання ключового слова не є спеціалізованою акустичною wake-word-моделлю: спочатку Android розпізнає мовлення, потім локальний парсер перевіряє «Джарвіс». Для надійної постійної активації потрібна окрема акустична модель і тестування на конкретних пристроях.

Пауза звукового запису на час синтезованої відповіді запобігає самоспрацьовуванню від TTS. Програма не передає розпізнану розмову до ШІ до активації. Сам `SpeechRecognizer` — системний сервіс Android із власною політикою обробки звуку.

## UI смартфона і годинника

- **Телефон:** повний екран із піксельним обличчям, текстовими повідомленнями, нотатками, налаштуванням ШІ та перемикачем розпізнавання імені.
- **Годинник:** компактний екран з обличчям, мікрофоном, статусом, короткою історією та меню дій. Використовується **той самий** парсер, ШІ-клієнт, нотатки й команди пристрою.
- Годинник із Wear OS повинен передавати `KEYCODE_STEM_1/2/3` у застосунок. Першою кнопкою живлення зазвичай керує система; підтримку бокової багатофункційної кнопки потрібно перевірити на пристрої.
- Не реалізована синхронізація нотаток телефону й годинника: дані залишаються локальними для кожного пристрою.

## Що потрібно для реальної роботи ШІ

1. Налаштувати оплату та ключ OpenAI API у своєму OpenAI Platform (не надсилати ключ у чат або APK).
2. Розгорнути особистий HTTPS Worker із `server/jarvis-ai-worker`, унести секрети `OPENAI_API_KEY` і `JARVIS_CLIENT_TOKEN` у секрети сервера.
3. У JARVIS натиснути «ШІ — підключення», увести HTTPS-адресу `/chat` і **окремий** серверний токен (не OpenAI API ключ). Токен зберігається в Android Keystore.
4. Надати модель/версію Wear OS годинника і перевірити, чи бокова кнопка передається застосунку.
5. Окремо дозволити збирання APK після завершення підключення. Зараз збірка навмисно не запускається.

## Перевірка без APK

```sh
javac -encoding UTF-8 -d /tmp/jarvis-wake-tests \
  android/app/src/main/java/com/andriy/jarvis/WakeConversation.java \
  android/app/src/test/java/com/andriy/jarvis/WakeConversationTest.java
java -cp /tmp/jarvis-wake-tests com.andriy.jarvis.WakeConversationTest
```

Ці тести **не** замінюють Android-компіляцію, перевірку Wear OS і реального голосового сервісу. Без прямого дозволу APK не збирати.

## Налаштування із телефона

Cloudflare Workers можна підключити через браузер телефону: вибрати GitHub-репозиторій `andriy2008-max/Jarvis-` та кореневу папку `server/jarvis-ai-worker`. Далі в Cloudflare створити runtime secrets `OPENAI_API_KEY` і `JARVIS_CLIENT_TOKEN`. Це не запуск Android APK і не вимагає передавати секрети в ChatGPT. Після розгортання ввести адресу `https://...workers.dev/chat` і особистий код доступу в інтерфейсі JARVIS. Інструкція у [server README](../server/jarvis-ai-worker/README.md).
