# JARVIS 0.1.8 — Android

**Стан:** виправлення ручного запису у вихідному коді. APK 0.1.8 ще не збирався. GitHub Actions у main запускається лише вручну (`workflow_dispatch`); для оновлюваного релізу потрібен той самий постійний ключ підпису.

## Що вже працювало у Preview 0.1.4

- Вебподібний Android-інтерфейс із піксельним синім обличчям, діалоговими картками, швидкими командами.
- Розпізнавання української мови, українські голосові відповіді, текстові команди.
- Універсальний запуск доступних для запуску програм за назвою.
- Нотатки в локальному сховищі, таймер усередині застосунку, системні будильники й нагадування, заряд батареї, набір номера без автоматичного дзвінка.
- Wear OS: обробка `KEYCODE_STEM_1/2/3`, лише коли система передає подію застосунку.

## Нові команди 0.1.5 (ще не тестувалися на телефоні)

| Команда | Дія |
| --- | --- |
| «Увімкни ліхтарик», «Вимкни ліхтарик» | CameraManager; запит CAMERA при першому використанні, якщо потрібний; не працює без спалаху |
| «Постав музику на паузу», «Продовж музику» | Відправляє медіаклавіші активному програвачу |
| «Наступна пісня», «Попередня пісня» | Відправляє команду переходу до іншого треку |
| «Постав гучність на 50%» | Установлює **медіагучність**, значення 0–100%, з округленням до кроку пристрою |
| «Вимкни звук», «Віднови звук» | Запам'ятовує і відновлює гучність **медіа**, не змінює режим дзвінка |
| «Відкрий налаштування екрана» | Відкриває системний екран налаштувань |

Керування музикою залежить від підтримки системних медіаклавіш активним програвачем. Джарвіс не може гарантувати керування кожним сервісом, не відкриває довільні файли або не запускає платний контент. Ліхтарик може бути недоступний, якщо камера зайнята іншою програмою.

Читай [RELEASE-SIGNING.md](RELEASE-SIGNING.md). **Постійного ключа в репозиторії немає.** Задано окремі `com.andriy.jarvis.preview` (debug) та `com.andriy.jarvis.stable` (підписаний release); стабільний ключ потрібно один раз створити та налаштувати в GitHub Secrets. Стара Preview 0.1.4 не зникає після переходу на окремий stable-пакет; нотатки автоматично не імпортуються.

## ШІ для вільного спілкування — 0.1.7

Реалізовано довільні текстові та голосові розмови через особистий HTTPS-сервер. Відомі команди телефону обробляються локально, решта фраз передається ШІ. Контекст із 14 останніх реплік зберігається тільки в оперативній пам'яті. Кнопка «ШІ — підключення» приймає HTTPS-адресу та окремий код доступу; **OpenAI API key не зберігається в Android**. Див. [AI-CONVERSATION.md](AI-CONVERSATION.md) і [сервер](../server/jarvis-ai-worker/README.md). Без розгортання сервера ШІ-відповіді недоступні.

## Активація «Джарвіс» і Wear OS

«Джарвіс, [запитання]» обробляється одним зверненням без проміжної голосової відповіді. Саме слово «Джарвіс» без продовження лише активує коротке очікування наступної фрази; після відповіді можна говорити без імені, а «Джарвіс, досить» завершує розмову. Новий компактний інтерфейс годинника використовує ті самі команди, ШІ, нотатки й налаштування, що й телефон. Експериментальна голосова активація без кнопки працює лише у відкритому застосунку за підтримки локального SpeechRecognizer на Android API 31+. За відсутності такої підтримки потрібен мікрофон або доступна фізична бокова кнопка Wear OS. Деталі: [VOICE-WAKE-AND-WEAR.md](VOICE-WAKE-AND-WEAR.md).

## Виправлення ручного запису у 0.1.8

- Натиснення «Говорити» запускає сеанс до **другого натискання**, навіть якщо системний SpeechRecognizer автоматично завершив короткий сегмент на тиші; застосунок відновлює розпізнавання й об'єднує текст сегментів перед надсиланням команди.
- Для ручного українського запису використовується звичайний Android SpeechRecognizer (за наявності), а локальне розпізнавання — лише для очікування «Джарвіс» у відкритому застосунку; обидва варіанти залежать від реалізації сервісу на пристрої.
- Після повторних технічних помилок запис може завершитися з повідомленням замість нескінченних перезапусків.
- **Оновлення APK:** не розповсюджувати тимчасово підписані Preview як оновлення. Для користувача лише stable-пакет із незмінним ключем та збільшеним `versionCode`. Див. [RELEASE-SIGNING.md](RELEASE-SIGNING.md).
