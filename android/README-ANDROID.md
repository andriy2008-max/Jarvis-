# JARVIS 0.1.2 — Android APK

Це вихідний код **нативного Android-застосунку**, окремого від `index.html` (вебдемо). Оновлений інтерфейс у `MainActivity.java` відтворює структуру вебверсії; після внесення змін **новий APK не збирався і не тестувався на пристрої**.

## Функції

- Українське голосове розпізнавання через системний `SpeechRecognizer` (потрібен встановлений на пристрої сервіс; іноді інтернет).
- Запит системного дозволу `RECORD_AUDIO` після натискання на мікрофон.
- Текстові команди, українські голосові відповіді через Android TTS, час/дата, локальні нотатки, відкриття сайтів.
- Піксельне обличчя: очікування, слухання, обробка, відповідь.
- Вебподібний мобільний інтерфейс: верхня панель, вітання, статус, синє коло, картки діалогу, перемикач TTS, шість швидких команд та список нотаток із видаленням.
- Нотатки та стан перемикача голосових відповідей зберігаються локально через `SharedPreferences`.
- Для годинника: обробка натискання `KEYCODE_STEM_1`/`STEM_2`/`STEM_3`, **лише якщо Wear OS передає цю кнопку застосунку, коли він відкритий**. Кнопка живлення часто зарезервована системою.

## Як отримати APK

1. **Тільки після прямої команди на збірку:** GitHub → **Actions** → **Android APK (Jarvis)** → **Run workflow** → `main` → **Run workflow**. Коміти й Pull Request **не запускають** APK workflow.
2. Після успіху завантаж артефакт `JARVIS-0.1.2-debug-APK` із завершеного запуску. Публікація нового APK у Releases потребує окремого кроку.
3. В Android відкрий APK і дозволь установку з цього джерела, коли Android запитає. Не плутай зі старим APK релізу `v0.1.2` — він створений до останнього редизайну.

## Перевірка перед майбутньою збіркою

- Java-синтаксис перевіряється без запуску Gradle/Android SDK. Це **не** доводить успішність Android-компіляції.
- На телефоні потрібно перевірити правильні safe-area відступи, вигляд при різних масштабах, TTS, мікрофон, нотатки, швидкі команди та анімацію.
- На Wear OS потрібно перевірити, що система передає події бокової кнопки.

## Збірка локально

Потрібен Android SDK API 35, JDK 17, Gradle 8.11.1.

```sh
gradle -p android :app:assembleDebug
```

Готовий APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Важливо

- APK підписано **тестовим debug-ключем GitHub runner**. Це прототип, не реліз для Google Play. Для стабільних оновлень потрібен постійний release-ключ.
- Цей APK **не використовує OpenAI API** й поки підтримує лише задані команди.
- Роботу кнопки на конкретному годиннику та голосовий сервіс треба перевірити на пристрої.

## Нові локальні голосові та текстові команди (вихідний код, APK ще не зібрано)

| Скажи або введи | Що виконає Android-застосунок |
| --- | --- |
| «Заряд батареї» | Покаже відсоток заряду пристрою |
| «Таймер на 5 хвилин» | Запустить таймер у відкритому застосунку, до 3 годин |
| «Скільки до кінця таймера» / «Скасуй таймер» | Покаже залишок або скасує таймер |
| «Гучніше» / «Тихіше» | Змінить медіагучність на один крок |
| «Вимкни голос» / «Увімкни голос» | Керування TTS із локальним збереженням налаштування |
| «Знайди рецепти борщу» | Відкриє Google-пошук у браузері |
| «Відкрий налаштування» / «Відкрий вайфай» / «Відкрий блютуз» | Відкриє відповідні налаштування Android |
| «Відкрий карти» | Відкриє Google Maps (вебпосилання) |
| «Набери 0501234567» | Відкриє номер у системній телефонній програмі, **не здійснює дзвінок автоматично** |
| «Видали нотатку 2» / «Видали останню нотатку» | Видалить окрему локальну нотатку |
| «Очисти нотатки» | Запитає підтвердження перед видаленням усіх нотаток |
| «Замовкни» / «Стоп» | Зупинить поточне озвучення |
| «Що ти вмієш?» | Перелічить доступні команди |

**Обмеження таймера:** таймер працює в процесі застосунку (Handler), а не як системний будильник. Якщо Android завершить застосунок у фоні, таймер не гарантовано спрацює. Не використовуй його для критичних нагадувань.

Перевірка синтаксису і розбору команд без Android SDK: `javac -encoding UTF-8 -d /tmp/jarvis-tests android/app/src/main/java/com/andriy/jarvis/CommandPatterns.java android/app/src/test/java/com/andriy/jarvis/CommandPatternsTest.java && java -cp /tmp/jarvis-tests com.andriy.jarvis.CommandPatternsTest`. Тестування команд на реальному Android залишається виконати після окремого дозволу на APK-збірку.

## Будильники, нагадування та запуск застосунків (код; ще не зібрано в APK)

Команди розбирає окремий Java-клас `AssistantIntents.java`. Джарвіс **не ставить будильник самостійно у фоні**, а відкриває встановлений системний «Годинник» з переданим часом і назвою. Перевір і підтвердь налаштування там; у різних виробників інтерфейс і підтримка назв можуть відрізнятися. Після встановлення системний будильник або таймер працює незалежно від активності Джарвіса. Для цього додано стандартний дозвіл `SET_ALARM`; спеціальний доступ до точних будильників застосунку Джарвіс не потрібен.

| Команда | Дія |
| --- | --- |
| «Постав будильник на 07:30» | Відкриє налаштування будильника на 07:30 у системному Годиннику |
| «Розбуди мене о 06:15» | Аналогічно — відкриє системний будильник |
| «Покажи будильники» | Відкриє перелік системних будильників |
| «Нагадай через 10 хвилин купити молоко» | Передасть текст і тривалість у системний таймер Годинника |
| «Нагадай о 18:30 тренування» | Відкриє будильник з назвою «Нагадування: тренування» |
| «Відкрий Telegram» / «Запусти Spotify» | Знайде програму серед доступних для запуску та відкриє її |
| «Відкрий застосунок Instagram» | Відкриє встановлений Instagram, якщо він доступний |

Обмеження: години — формат `HH:mm` від 00:00 до 23:59, **будильники вказують наступне спрацювання у Годиннику**, не конкретну календарну дату. «Завтра о…», нагадування з повторенням або за адресою ще не підтримуються — Джарвіс повертає приклад доступного формату, не створюючи неправильне нагадування. Відносні нагадування — від 1 секунди до 24 годин. Якщо на пристрої немає застосунку, який обробляє `ACTION_SET_ALARM`/`ACTION_SET_TIMER`, Джарвіс повідомить про це.

Android 11+ обмежує видимість інших програм: у `AndroidManifest.xml` декларується лише запит застосунків із `MAIN`+`LAUNCHER`, **не** дозвіл `QUERY_ALL_PACKAGES`. Розпізнавання встановленого застосунку відбувається за його видимою назвою та кількома українськими варіантами назв. Неоднозначні збіги не запускаються автоматично. YouTube, Telegram, Gmail, ChatGPT і Google мають попередній вебваріант, якщо відповідного встановленого застосунку не знайдено.

### Перевірка без APK

```sh
javac -encoding UTF-8 -d /tmp/jarvis-parser-tests \
  android/app/src/main/java/com/andriy/jarvis/CommandPatterns.java \
  android/app/src/main/java/com/andriy/jarvis/AssistantIntents.java \
  android/app/src/test/java/com/andriy/jarvis/CommandPatternsTest.java \
  android/app/src/test/java/com/andriy/jarvis/AssistantIntentsTest.java
java -cp /tmp/jarvis-parser-tests com.andriy.jarvis.CommandPatternsTest
java -cp /tmp/jarvis-parser-tests com.andriy.jarvis.AssistantIntentsTest
```

Синтаксичні тести не замінюють Android-компіляцію чи перевірку на реальному телефоні. **Workflow збірки APK залишається ручним; збірка не запускалася.**
