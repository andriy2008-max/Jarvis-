# JARVIS 0.1.2 — Android APK

Це **нативний Android APK**, окремий від `index.html` (вебдемо). Джарвіс працює в повноекранному інтерфейсі з 8-бітним обличчям.

## Функції

- Українське голосове розпізнавання через системний `SpeechRecognizer` (потрібен встановлений на пристрої сервіс; іноді інтернет).
- Запит системного дозволу `RECORD_AUDIO` після натискання на мікрофон.
- Текстові команди, українські голосові відповіді через Android TTS, час/дата, локальні нотатки, відкриття сайтів.
- Піксельне обличчя: очікування, слухання, обробка, відповідь.
- Для годинника: обробка натискання `KEYCODE_STEM_1`/`STEM_2`/`STEM_3`, **лише якщо Wear OS передає цю кнопку застосунку, коли він відкритий**. Кнопка живлення часто зарезервована системою.

## Як отримати APK

1. GitHub → **Actions** → **Android APK (Jarvis)** → успішний запуск → **Artifacts** → `JARVIS-0.1.2-debug-APK`.
2. Після об'єднання в `main` workflow публікує прямий `.apk` у **Releases** → `v0.1.2` (якщо дозволено запис через GitHub Actions).
3. В Android відкрий `.apk` й дозволь установку з цього джерела, коли Android запитає.

## Збірка локально

Потрібен Android SDK API 35, JDK 17, Gradle 8.11.1.

```sh
gradle -p android :app:assembleDebug
```

Готовий APK: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Важливо

- APK підписано **тестовим debug-ключем GitHub runner**. Це прототип, не реліз для Google Play. Для стабільних оновлень потрібен постійний release-ключ.
- Цей APK **не використовує OpenAI API** й поки підтримує лише задані команди.
- Роботу кнопки на конкретному годиннику та голосовий сервіс треба перевірити на пристрої.
