# Дімон 0.1.41 — Google Pixel 9: ручний чек-лист

**Статус: тестовий реліз 0.1.41, versionCode 51; фізично ще не підтверджено.** Той самий пакет `com.andriy.jarvis.stable`, початковий сертифікат; встановити поверх 0.1.40 без видалення даних. Телефон Pixel із root, але жодна з нових змін не вимагає root.

## Spotify — нова користувацька помилка
- [ ] «Увімкни пісню Пачка сигарет» коли Spotify відкрито на екрані «Пошук»: Дімон НЕ натискає нижню вкладку повторно.
- [ ] Натискає великий білий рядок «Що ви хочете послухати?» зі скриншота, навіть коли текст Spotify Compose не має ACTION_CLICK.
- [ ] Коли рядок не видимий у дереві Accessibility, лише на підтвердженому екрані Search (верх «Пошук», картки «Музика» і «Подкасти») виконується натискання проміжку.
- [ ] Перевіряє фактичне відкриття редактора перед введенням; якщо рядок не спрацював, робить максимум 3 повторні спроби; відсутність поля — чітка помилка, без введення в інший застосунок.
- [ ] Вводить назву (українська/російська/англійська), натискає Enter/Пошук, вибирає першу ПІСНЮ з відповідною назвою, підтверджує назву в мініпрогравачі.
- [ ] Повторити з відкритих вкладок Home, Library та мініпрогравача; Spotify не завершує Дімона після виконання.
- [ ] «Увімкни плейлист», «Увімкни реп», «Увімкни українське», «Увімкни музику» — попередні алгоритми не зламані.

## Телефонні сценарії та міжпристрійна інтеграція
- [ ] Bolt «Дімон, таксі [адреса]»: чекати завантаження, «Рушаймо» → «Місце висадки» → ввід → Enter → перша адреса; немає натискань у порожній екран.
- [ ] Telegram: вибір контакту, текст повідомлення, підтвердження/скасування, без дублікатів.
- [ ] Ввід «Напиши ...», натисни/утримуй/свайпни, правильна дія в активній програмі.
- [ ] Системні команди: звук, Wi-Fi, Bluetooth, ліхтарик, «Не турбувати», таймер/будильник.
- [ ] JARVIS Finance: створення витрат/доходів, категорії, рахунки, бюджети, звіти й збережені дані; попередня версія не стирається при оновленні. (Не стверджувати, що усі функції доступні, доки не перевірено.)
- [ ] Макроси: тригер → дії → обмеження, без дубльованих запусків.
- [ ] Watch7 → Pixel: команди доходять, виконується рівно одна дія, результат повертається на годинник.
- [ ] Від'єднати Pixel/Watch7 під час команди і повторно підключити: без аварії та нескінченних очікувань.
- [ ] Мікрофон гарнітури та мікрофон телефона: новий примусовий режим Watch7 НЕ змінює телефонний вибір джерела звуку.
- [ ] Дімон працює у фоновому режимі настільки, наскільки дозволяє Android; після повернення коректно відновлює діалог.
- [ ] ⋮ → Діагностика → Журнал роботи: перегляд, копія, поділитися, очистити, без паролів і API-ключів.

**Після фізичної перевірки надіслати помилки з командою, скриншотом та часом; не видавати неперевірене за підтверджене.**
