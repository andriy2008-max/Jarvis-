# JARVIS 0.1.33 — Чекліст №2: Інші зміни, функції телефону та Watch7

Кандидат: `release/jarvis-0.1.33-finance`. Основа: чинний `main` JARVIS 0.1.32, доповнений Finance v6. Примітка: загальні функції нижче **успадковані з 0.1.32**, а не всі вперше додані в 0.1.33. Підтверджено наявність відповідного коду; індивідуальну працездатність на реальному пристрої ще не доведено.

## Інтеграція та загальна поведінка

- [x] Версія `0.1.33`, `versionCode 43`, стабільний пакет `com.andriy.jarvis.stable` зі збереженням штатного сертифіката (якщо Release Secrets доступні).
- [x] Збережено основні екрани/команди попереднього Джарвіса без створення Finance як другої окремої програми.
- [x] Голосова/текстова маршрутизація телефонних і годинникових запитів до єдиного фінансового реєстру Pixel.
- [x] Служба `JarvisCompanionService` для фонової доставки Wear Data Layer команд із постійним сповіщенням, яку можна вимкнути.
- [x] Локальні макроси зі сценаріями дій, обмеженнями й окремим інтерфейсом `JarvisMacroActivity`.
- [x] Wear запит на встановлення будильника через телефонний годинник; сувора перевірка часу.
- [x] Правила анімації мікрофона Watch7: показувати «слухає» лише за активної готової сесії, а не просто за текстом на екрані.
- [x] Spotify: налаштування офіційного App Remote SDK, Spotify Client ID, відповідність назви плейлиста/треку URL; залишено також варіанти екранного керування.
- [x] Bolt: розпізнавання голосової адреси та виклик сценарію керування телефоном.
- [x] Збережені команди відтворення/звуку, ліхтарика, відкриття програм, жестів екрана, набору тексту, пошуку, таймера, нотаток та інших попередніх можливостей (залежно від дозволів).
- [x] Підключення Telegram через MTProto і налаштування голосових відповідей залишаються в коді.
- [x] Наявний зовнішній Money Manager не є джерелом правди для Finance: новий облік виконується всередині JARVIS.

## Що треба перевірити на Pixel + Galaxy Watch7

- [ ] 0.1.33 встановлюється поверх наявного stable JARVIS без помилки «Програму не встановлено», без дублювання іконок і зі збереженням нотаток/налаштувань.
- [ ] Годинник запускає мікрофон кнопкою; після відкриття анімації вуха розпізнає повний вислів; команди надходять на Pixel.
- [ ] Годинник не закриває JARVIS після команди та вимовляє «скажи…»; аудіо відповіді чутно.
- [ ] Болт: відкриття → «Поїздки рушаймо» → місце висадки → адреса → пошук/Enter.
- [ ] Spotify: пошук треку українською/російською/англійською, вибір першого результату, Play, плейлисти через обраний спосіб.
- [ ] Будильник із Watch7 реально створюється на Pixel, не лише відображає повідомлення.
- [ ] Служба фону та отримання команд після закриття екрана, перезапуску застосунку та перезавантаження телефона.
- [ ] Таймер/вібрація, плаваюче лице, режим керування екраном, жестове керування, макроси, Spotify/TG, звук і ліхтарик.
- [ ] Робота дисплея та жестів Watch7 у режимі енергозбереження — обмежується правилами Wear OS; гарантувати постійний екран програмно неможливо.
- [ ] Мовлення Дмитра/Лади та офлайн-розпізнавання лише після фактичного підтвердження моделей/даних на пристрої.

## Особливості цієї версії

- [x] Найсуттєвіша нова функція 0.1.33 — **вбудований зашифрований Finance**; інші перелічені функції переважно перенесені з базової версії 0.1.32.
- [ ] Результати компіляції та перевірки підпису заповнюються тільки за підсумками реального APK workflow.
- [ ] Результат ручного тестування залишається відкритим до встановлення APK на обидва пристрої.

Це незалежний чекліст загального JARVIS; окремий файл `android/RELEASE-0.1.33-FINANCE-CHECKLIST.md` містить саме перевірки фінансового менеджера.
