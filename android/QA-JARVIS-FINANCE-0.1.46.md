# JARVIS Finance 0.1.46 — чекліст

Вбудований фінансовий менеджер з шифрованою локальною базою SQLCipher **на Pixel**. Жодного стороннього Money Manager API. Перед оновленням не видаляти Дімона; за можливості експортувати резервну копію фінансів.

## Рахунки та записи
- [ ] Відкривається «💰 JARVIS Finance» з вкладками «Огляд», «Операції», «План», «Звіти».
- [ ] Рахунки «Готівка» та «Mono» мають правильні залишки; переказ між ними не рахується доходом.
- [ ] «Витратив 150 готівка транспорт таксі» створює рівно одну витрату **−150 UAH**.
- [ ] «Заробив 350 готівка чайові столик 5» створює рівно один дохід **+350 UAH**.
- [ ] «Баланс рахунків», «Скільки витратив сьогодні», «Залишок бюджету» повертають правильні дані.
- [ ] «Не 150, а 180» змінює останній потрібний запис без дублювання.
- [ ] Редагування, скасування транзакцій і регулярні операції не створюють зайвих проводок.

## Watch7, безпека, резервування
- [ ] Команда витрати з Watch7 надходить на Pixel, на годиннику є підтвердження.
- [ ] Повторна доставка того самого ID не створює другого запису.
- [ ] Тимчасова помилка Pixel/з'єднання **не видаляє** фінансову команду з черги Watch7.
- [ ] Після відновлення зв'язку черга передається, у Pixel тільки один правильний запис.
- [ ] Нерозпізнана команда не змінює баланс.
- [ ] Суми й бюджети у звітах збігаються з транзакціями.
- [ ] CSV-експорт відкривається. Зашифрована резервна копія створюється й відновлюється за правильним паролем.
- [ ] Невірний пароль не впливає на дані.
- [ ] **Оновлення з 0.1.45 до 0.1.46** зберігає рахунки, транзакції та ключі шифрування.

Автоматичні тести перевіряють фінансову схему, голосові правила й контракти черги; фізична перевірка користувачем обов'язкова.
