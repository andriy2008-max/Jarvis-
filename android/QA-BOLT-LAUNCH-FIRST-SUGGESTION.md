# JARVIS Bolt — завантаження, попередній екран, перша адреса

**Статус:** виправлення записано у вихідний код на основі v0.1.36.
**APK не зібрано**. Автоматичні перевірки не замінюють фізичний тест Pixel.

## Новий алгоритм

1. Відкрити Bolt (пакет ee.mtakso.client).
2. Дочекатися щонайменше 4 секунд **і двох послідовних підтверджень** стану екрана. Якщо Bolt показує завантаження — перевіряти ще через 2 секунди. Загальний захисний ліміт 90 секунд, без сліпих натискань.
3. Якщо Bolt відкрився не на головній сторінці, послати системну **«Назад» максимум двічі**, після кожної — знову визначити екран. На підтвердженому HOME не натискати «Назад» ще раз (інакше Bolt може закритися).
4. Лише після підтвердження HOME натискати «Рушаймо». Не натискати на splash, невідомій сторінці, у вікні оплати чи підтвердження.
5. Дочекатися сторінки «Маршрут» і поля «Місце висадки», ввести текст у власне поле Bolt.
6. Натиснути Enter один раз і чекати появи списку адрес. Ніяких повторних Enter.
7. Знайти **перший видимий рядок підказок**, як «A Hotel by Apartel» на знімку власника. Натиснути на його реальні межі, а не на фіксований Y. Натискання вважається виконаним лише після завершення жесту.
8. Якщо Accessibility Джарвіса не бачить рядок, а Mobilerun Portal налаштований — резервне локальне зчитування та натискання першої підказки, тільки в Bolt. Якщо жоден метод не бачить результати — повідомити про помилку, не торкатися навмання.
9. Поїздка не замовляється і не оплачується автоматично.

## Чекліст Pixel

- [ ] При холодному запуску Bolt повільно завантажується: Джарвіс повідомляє «Чекаю» і не натискає порожній екран.
- [ ] При швидкому запуску Bolt HOME розпізнається й «Рушаймо» натискається один раз.
- [ ] Якщо Bolt залишився на «Маршрут», Джарвіс виконує Back, перевіряє HOME та продовжує.
- [ ] Якщо Bolt залишився в пошуку адреси з клавіатурою, Джарвіс робить не більш як два Back; якщо HOME не з’явився — зупиняється.
- [ ] Якщо HOME з'явився після першого Back, другий **не** виконується, щоб не закрити Bolt.
- [ ] Після «Рушаймо» сторінка «Маршрут» справді з'являється до натискання «Місце висадки».
- [ ] Після введення адреси Enter натискається **один раз**.
- [ ] Якщо підказка адреси відображається (наприклад «A Hotel by Apartel»), Джарвіс натискає **перший її рядок**, не на верхнє поле і не на стрілку «Назад».
- [ ] Після дотику потрібний пункт призначення відображається на Bolt; якщо не вдалося, Джарвіс повідомляє помилку, не дублює дотик.
- [ ] Без налаштованого Portal працює вбудована Accessibility.
- [ ] З налаштованим Mobilerun Portal можна вибрати підказку, якщо її немає у дереві Accessibility Джарвіса.
- [ ] Коли інша програма на передньому плані, Джарвіс не натискає жодних координат Bolt.
- [ ] Жодних автоматичних замовлень поїздки, оплат і підтверджень.
- [ ] Джарвіс на Watch7 залишається відкритим і повідомляє результат дій.
- [ ] JARVIS Finance, локальні таймери Watch7, Spotify App Remote та інші функції 0.1.36 працюють як раніше.

## Результат знімка

На наданому скриншоті перший рядок адреси: **«A Hotel by Apartel»**, другий рядок описує місце у Східниці. Це **підказка пошуку**, а не кнопка остаточного замовлення таксі.

## Необхідна перевірка

У GitHub Actions: Java тести BoltUiLabels + компіляція Android без APK.
На реальному Pixel: перевірити всі сценарії вище, бо Bolt може приховувати частину дерева елементів.
