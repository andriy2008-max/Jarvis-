# JARVIS Finance 0.1.34 — чекліст

Основа: реліз 0.1.33 (повний локальний зашифрований SQLCipher-журнал). Не замінювати дані чи не скидати застосунок. У 0.1.34 додана коротка форма запису, інші можливості 0.1.33 збережено в коді. Перевірки на реальних Pixel/Watch7 виконуються користувачем після встановлення.

## Pixel
- [ ] Після оновлення старі рахунки, записи, бюджети, нагадування, плани та звіти збереглися.
- [ ] `витратив 150 готівка транспорт таксі` → витрата 150 ₴, готівка, Транспорт, примітка «таксі».
- [ ] `потратив 50 моно транспорт автобус до роботи` → витрата 50 ₴, карта моно, Транспорт, примітка «автобус до роботи».
- [ ] `заробив 350 готівка чайові столик 5` → дохід 350 ₴, готівка, чайові, примітка «столик 5».
- [ ] `заробив 15000 карта моно зарплата за листопад` → дохід, правильна категорія, примітка.
- [ ] Якщо назва рахунку у власному журналі інша — налаштувати псевдонім у Фінансах.
- [ ] `портатив 150 готівка транспорт` НЕ додає операцію.
- [ ] Звичайні команди 0.1.33 `запиши витрату...`, `витратив 150 на каву позавчора`, `чайові 650 готівкою` залишилися працездатні.
- [ ] `скільки я витратив сьогодні?`, `який баланс?`, `що з бюджетом?` відповідають на основі власного журналу.
- [ ] Одна голосова команда не створює повторного запису при повторній доставці того самого ідентифікатора.

## Galaxy Watch7
- [ ] З'єднання з Pixel активне, без створення другої бази фінансів.
- [ ] Команди `витратив`, `потратив`, `заробив` передаються на Pixel, відповідь повертається на Watch7.
- [ ] Примітка точно відображається в записі на Pixel.
- [ ] Звіти та баланси читаються з Pixel лише за дозволених налаштувань блокування.
- [ ] Джарвіс не закривається після виконання фінансової команди.

## Увага
Фінансові дані зберігаються у власній захищеній базі JARVIS Finance, а не автоматично синхронізуються із зовнішнім «Менеджером фінансів». Перевір назви рахунків і зроби резервну копію перед оновленням.
