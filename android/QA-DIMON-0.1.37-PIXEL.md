# Дімон 0.1.37 — чек-лист Google Pixel (стабільна APK)

## Відомості про збірку
- Вихідний код: `andriy2008-max/Jarvis-`, гілка `main`, з окремим workflow збірки.
- Android package: `com.andriy.jarvis.stable` (не змінювати).
- Версія: `0.1.37`, `versionCode 47` (оновлення після 0.1.36).
- Цільова назва застосунку: **Дімон**; старі внутрішні імена пакета/налаштувань залишаються для сумісності.
- Перевірка CI та на реальному Pixel — різні речі.

## Перевірка встановлення
- [ ] За потреби експортувати нотатки/фінанси, не видаляти стару stable-копію.
- [ ] Встановити `0.1.37` поверх **stable** `0.1.36` (однаковий package і сертифікат).
- [ ] Перевірити, що застосунок називається «Дімон», дані збереглися та встановлюється без `App not installed`.
- [ ] Перевірити root-дозволи, доступ до спеціальних можливостей, мікрофона, сповіщень і роботи у фоні.

## Мікрофон, режими й керування екраном
- [ ] «Дімон» активує звичайний режим / ШІ; «Дімон, котра година?» розпізнається.
- [ ] Струшування + «Дімон» працює так само, як колишнє звертання.
- [ ] «Дімон, телефон» входить у режим керування; «Дімон» повертає у звичайний режим.
- [ ] «Дімон, натисни пошук», «зажми», «напиши ...», «свайпни» виконуються на екрані.
- [ ] Кожна дія має зрозумілий статус або Toast, без передчасного натискання.
- [ ] Іконка плаваючого помічника не зникає після виконання, а служба отримує команди з Watch7.
- [ ] Старе звертання «Джарвіс» ще працює як резервний псевдонім.

## Spotify і Bolt
- [ ] «Дімон, увімкни пісню [назва]»: Spotify, пошук, введення, вибір **першої відповідної пісні**, перевірка назви мініпрогравача.
- [ ] Вивести дві однакові за назвою пісні різних виконавців; перевірити перший результат.
- [ ] «Дімон, увімкни плейлист [назва]»: «Моя бібліотека», пошук, запуск відтворення.
- [ ] Повторити з відкритим Spotify у вкладці «Пошук» і у вкладці «Моя бібліотека».
- [ ] «Дімон, таксі [адреса]»: Bolt завантажується повністю, якщо потрібно, двічі «Назад»,
      натискання «Рушаймо»/«Місце висадки», введення й вибір **першого варіанта адреси**.
- [ ] Якщо потрібна кнопка не з'являється — повторна перевірка з паузою 2 с, без випадкових натискань.

- [ ] Вбудований менеджер фінансів: запис доходу/витрати, баланс, категорії, звіти, бюджети.
- [ ] Таймер, будильник, системні перемикачі та ліхтарик працюють після оновлення.
- [ ] Макроси: тригери, дії та обмеження збереглися.
- [ ] ШІ представляється Дімоном **лише після розгортання оновленого Cloudflare Worker**.
- [ ] Перевірити з'єднання з годинником, передавання команд і відповіді.

**Статус:** це план ручної перевірки, а не твердження про проходження тесту на Pixel.
