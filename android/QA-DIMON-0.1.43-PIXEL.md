# Дімон 0.1.43 — Pixel QA

Версія 0.1.43 (versionCode 53), пакет com.andriy.jarvis.stable, оригінальний стабільний ключ.

## Виправлено
- «Увімкни пісню Мама» — раніше Spotify завершував пошук, але не натискав перший результат без точно видимого Accessibility-тексту.
- Тепер спочатку шукає перший результат за назвою та Song/Пісня-міткою, але якщо Spotify Compose не надає рядок, після підтвердженого Enter пробує координатний жест по першому результату в активному Spotify, приблизно X=центр, Y=510 для екрана 1080×2400. Жодних натискань до завершення пошуку або при активній клавіатурі.
- Нові голосові команди «інша пісня», «не та пісня» (також «наступна пісня», «іншу пісню», «не ту пісню»). Повторний виклик автоматично повертається до попереднього пошуку, обирає другий, потім третій результат зі списку.
- Контекст пошуку зберігається лише в пам'яті застосунку до 10 хвилин. Для нового запиту індекс скидається.
- Список телефону не змішується зі списком Watch7. Коли список недоступний, Дімон не натискає випадкові елементи.

## Ручний чек-лист Pixel 9
- [ ] Встановлення поверх попередньої підписаної версії без видалення даних.
- [ ] «Увімкни пісню Мама» зі вкладки Пошук; клацання першого результату й звук.
- [ ] «Увімкни пісню Я вільний»; зникає стара помилка про недоступний результат.
- [ ] «Інша пісня»: знову з'являється список того самого запиту, вибирається другий результат.
- [ ] «Не та пісня»: знову вибирається наступний, третій результат.
- [ ] Повторити «Інша пісня» ще декілька разів; порядок не скидається сам собою.
- [ ] Після нового «Увімкни пісню [інша назва]» результат знову починається з першого.
- [ ] Команда «Інша пісня» без попереднього пошуку — зрозуміле повідомлення, без натискань.
- [ ] Під час виконання перейти до іншої програми; Дімон не повинен натискати її.
- [ ] Команди працюють із голосу, текстового чату та через активний режим керування.
- [ ] Перевірити повідомлення на екрані після кожного етапу.
- [ ] Програти українські, російські й англомовні назви.

Уточнення: у Pixel fallback автоматично калібрується для видимих перших п'яти результатів; подальші результати потребують доступних Accessibility-вузлів. Не гарантується фізична робота без ручного тесту на вашому Spotify.
