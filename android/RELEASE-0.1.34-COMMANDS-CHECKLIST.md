# JARVIS 0.1.34 — Bolt, Spotify, Watch7 та фонова робота

Основа збірки: v0.1.33 + вибіркові виправлення. Перевірка коду та компіляції автоматична, **відтворення музики і натискання на реальних Pixel 9/Watch7 не може бути перевірене CI**.

## Bolt
- [ ] Розблокуй Pixel, увімкни «Джарвіс — керування екраном» у спеціальних можливостях.
- [ ] З Watch7: `таксі Стебник дім` або `таксі до [адреса]`.
- [ ] Bolt відкрився; через 4 секунди спроба натиснути «Рушаймо» (тільки якщо Bolt на передньому плані).
- [ ] Зникла помилка `TAP_RUSHAYMO_PREP UnsupportedOperationException` (DisplayManager замість забороненого Context.getDisplay).
- [ ] Через 2 секунди відкривається «Місце висадки».
- [ ] Адреса вводиться в поле Bolt один раз, потім Enter один раз.
- [ ] Bolt відобразив потрібні результати. Замовлення/оплата поїздки автоматично **не виконуються**.
- [ ] Для іншої роздільності екрана координати можуть потребувати перекалібрування — без випадкових натискань.

## Spotify
- [ ] `увімкни пісню [назва]` → вкладка Пошук; якщо вже там, зайвих натискань немає.
- [ ] Поле пошуку активується; за відсутності поля через 2 секунди повторна перевірка вкладки **один раз**.
- [ ] Вводить повну назву українською, російською або англійською, надсилає Enter.
- [ ] Спочатку натискає доступний рядок першої знайденої пісні, резервно — точку Y=510 тільки після перевірки точного запиту.
- [ ] `увімкни плейлист [назва]` → Моя бібліотека, навіть коли вкладка була вже відкрита; шукає точну назву.
- [ ] Після відкриття плейлиста натискає рядок першої пісні зі списку, **не зелену Play**.
- [ ] `увімкни реп` → Моя бібліотека → Пісні, що сподобалися → фільтр Реп → рядок першої пісні, не Play.
- [ ] Якщо список недоступний або невизначений, Джарвіс повідомляє помилку, а не натискає довільну кнопку.
- [ ] Джарвіс не закривається після команди Spotify. Аудіо та фактичний запуск перевіряються вручну на Pixel.

## Watch7 та фон
- [ ] Watch7: видиме обличчя Джарвіса продовжує працювати після відповіді.
- [ ] Ongoing Activity: сповіщення активного сеансу дозволене, є швидке повернення до Джарвіса з циферблата.
- [ ] Плаваюче обличчя Pixel залишається активним після виконання команди.
- [ ] Android може вимикати екран у режимі економії — це системне обмеження, не безумовна гарантія Always On.
- [ ] Телефон і годинник використовують той самий пакет та версію 0.1.34; підпис оригінальний.
- [ ] Голосова команда `скажи [фраза]` на Watch7 озвучується без закриття програми.
- [ ] Команди таймера/будильника та передача на Pixel не регресували.

## При несправності
Зроби скриншот поточного екрана і тексту помилки Джарвіса. Не повторюй команду з оплатою/поїздкою навмання. Білд не може підтвердити реальну навігацію Spotify/Bolt без тесту на твоєму пристрої.
