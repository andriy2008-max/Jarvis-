# JARVIS Finance — голосове керування з Samsung Galaxy Watch7

**Архітектура:** Журнал і баланс належать Pixel. Watch7 — лише голосовий інтерфейс, захищена черга й показ результатів.

## Перевірки саме на годиннику

- [ ] Дімон не закривається після відкриття мікрофона, першої і наступних команд.
- [ ] `Витратив 150 готівка транспорт таксі` — збереження НА PIXEL у JARVIS Finance.
- [ ] `Потратив 50 моно транспорт автобус` — запис на карту моно; відповідь на Watch7.
- [ ] `Заробив 350 готівка чайові столик п'ять` — дохід, примітка, голосова/текстова відповідь.
- [ ] `Дімон, заробив 15000 моно зарплата за листопад` — дохід, а не витрата.
- [ ] `Витрата кава 85` — запис на стандартний рахунок лише якщо він заданий.
- [ ] `Не 85, а 95` — виправлення тієї самої операції, не створення дубліката.
- [ ] `Встанови бюджет на транспорт 2000 грн` — змінює бюджет на Pixel.
- [ ] `Баланс рахунків`, `Покажи бюджет на транспорт`, `Залишок бюджету`.
- [ ] `Скільки я витратив сьогодні?`, `Фінансовий звіт`.
- [ ] `Відкрий фінанси` — пояснює, що повний екран є на Pixel, замість запуску невідомого застосунку.
- [ ] Pixel тимчасово недоступний: команда зберігається в захищеній черзі,
      годинник показує «очікує Pixel», не вигадує успішне збереження.
- [ ] Відновити Bluetooth/Wi-Fi: фінансова команда надсилається ПОВТОРНО
      з тим самим ID та зафіксованим часом.
- [ ] Перевірити підтвердження з Pixel і відсутність дублів навіть при втраті ACK.
- [ ] Черга до 20 команд: не втрачає й не перемішує порядок; не надсилає в AI.
- [ ] `Скасуй витрату` — скасовує лише ще НЕ надісланий запис; для вже виконаного пояснює перевірку журналу.
- [ ] Фінансові записи не запускають сторонній Money Manager і не відкривають його на Pixel.
- [ ] Якщо Pixel заблокований, приватні баланси не озвучуються без явної дозволеної настройки.
- [ ] Після фінансової команди можна знову слухати, відповідати голосом і повертатися до інтерфейсу.

## Регресія інших Watch7-команд

- [ ] Spotify (відкриття, пісня, плейлист, реп, українське) — локально на Watch7.
- [ ] Google Карти `Де я`, `Знайди дорогу до …` — Watch7.
- [ ] Bolt `Дімон таксі …` — на Pixel із результатом на Watch7.
- [ ] `Телефон`, `Натисни`, `Свайпни`, `Напиши` — керування Pixel.
- [ ] Будильники, таймери, нотатки, ШІ, текстові та голосові відповіді.
- [ ] Після кожної з 20 різних команд Дімон лишається доступним;
      якщо повертається на циферблат, зібрати Watch7 logcat.

## Статус

Це сценарії для реальної перевірки на Samsung Galaxy Watch7.
Автоматичні парсерні тести та Android-компіляція **не** підтверджують
фактичну передачу Bluetooth, запуск іншого застосунку або стабільність UI.
