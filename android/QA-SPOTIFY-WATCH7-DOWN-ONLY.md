# Galaxy Watch7 — Spotify без свайпів вправо й угору

Стан: зміни в коді, APK не збирати без прямої команди.

## «Увімкни пісню …» / «Не та пісня»
- [ ] Spotify відкривається саме на Watch7, не на Pixel
- [ ] Якщо іконка «Пошук» уже видима, натиснути її без жодного свайпу
- [ ] Інакше зробити один **довгий свайп униз** (зверху донизу), перевірити іконку
- [ ] Якщо іконки немає, повторити **тільки вниз**, максимум три свайпи загалом
- [ ] Не робити свайпів вправо, вліво чи вгору; після третьої спроби показати помилку без випадкового натискання
- [ ] Натиснути «Пошук», ввести назву, підтвердити пошук
- [ ] Вибрати перший результат; якщо це плейлист — відкрити його й натиснути Play
- [ ] Після підтвердження Play не свайпати вправо: повернутися до Джарвіса та слухати «Не та пісня»
- [ ] «Не та пісня» відкриває Spotify, знаходить пошук через іконку або свайпи **тільки вниз** і вибирає наступний результат
- [ ] При наступному плейлисті — знову Play, без виходу вправо
- [ ] Після кожного кроку користувач бачить коротке повідомлення про дію

## Регресії
- [ ] «Увімкни плейлист [назва]» продовжує шукати плейлист в бібліотеці й натискає Play
- [ ] Жодна автоматична дія Spotify Watch7 не використовує RIGHT/UP
- [ ] Google Maps має власну навігацію: короткий свайп вгору для «Пішки» залишається незмінним
