# Дімон 0.1.42 — Pixel QA (телефон)

Версія: `0.1.42`, versionCode 52, пакет `com.andriy.jarvis.stable`. Це тестовий підписаний кандидат. Фізично на Pixel не перевірено.

## Нова проблема за скриншотом
Користувач промовив «включи пісню я вільний», а Дімон повернув:
«Не вдалося натиснути рядок «Що ви хочете послухати?» у Spotify».
У Spotify на Pixel було видно біле поле пошуку, але його Accessibility-вузли не дозволили здійснити натискання.

## Код у 0.1.42
- Спершу стандартно перевіряє вкладку «Пошук» і намагається знайти поле через Accessibility, не натискаючи інші елементи.
- Якщо поле не знайдене, через 1,8 секунди намагається натиснути вручну підтверджену користувачем точку: центр по ширині та 17,5% висоти **реального екрана Pixel** (приблизно X=342,Y=269 для скриншота 684×1536).
- Дозволено не більше двох координатних спроб, тільки якщо Accessibility підтверджує видимий Spotify і телефон у портретному режимі; не застосовує координату Watch7.
- Під час жесту приховує плаваюче обличчя Дімона; чекає колбек завершення жесту.
- Після натискання **окремо перевіряє** появу редагованого поля або Spotify-належної клавіатури перед уведенням назви. Не вважає натискання підтвердженням відтворення.
- Відмінність від 0.1.41: наявність білого поля візуально більше не вимагає, щоби Compose віддав його текст через Accessibility — це резервний шлях після невдалого пошуку елемента.
- `SpotifyTrackSearchRulesTest`: перевірка пропорцій із скриншота, обмеження кількості натискань, заборона натискання на іншому застосунку / Watch7 / відкритому полі.

## Ручний чек-лист
- [ ] Увімкнути Spotify, відкрити вкладку «Пошук» вручну.
- [ ] Сказати «Включи пісню Я вільний»; перевірити саме натискання білого поля.
- [ ] Перевірити появу клавіатури, введення `Я вільний`, Enter/Пошук.
- [ ] Перевірити вибір першого релевантного результату і мініпрогравач.
- [ ] Повторити запуск із вкладок «Головна», «Моя бібліотека», із вже відкритим плеєром.
- [ ] Повторити для української, російської та англійської назви.
- [ ] Залишити Spotify під час автоматизації: Дімон не повинен натискати інші застосунки.
- [ ] Перевірити сповіщення про кожну дію; при двох невдалих натисканнях — зрозуміла помилка.
- [ ] Перевірити сумісність оновлення поверх 0.1.41 без видалення даних.

**Обмеження:** Жодний тест на GitHub не може довести реальне натискання в поточному Spotify на фізичному Pixel. Для цього потрібне ручне QA.
