# JARVIS 0.1.30 — чек-лист після встановлення на Pixel 9 + Galaxy Watch7

**Збірка:** `versionCode=40`, `versionName=0.1.30`, `applicationId=com.andriy.jarvis.stable`.
**Сумісність:** той самий сертифікат підпису, що й попередній stable APK 0.1.29. Збирати та встановлювати поверх 0.1.29, НЕ видаляти старий застосунок.
**Статус:** CI перевіряє компіляцію, автоматичні тести, підпис APK, сертифікат, версію й контрольну суму. Фізичні взаємодії з Bolt, Spotify, Watch7, мікрофоном, заблокованим екраном CI не може гарантувати; пункти нижче треба перевірити на реальних пристроях.

## 0. Інсталяція та ідентичність
- [ ] Pixel: встановити `JARVIS-0.1.30-stable.apk` поверх 0.1.29; нотатки/дозволи/налаштування збережені.
- [ ] Galaxy Watch7: встановити ТОЙ САМИЙ APK через Wear Installer/ADB; це universal Android/Wear OS APK, дозволи мікрофона надати на годиннику.
- [ ] В Android інформації про застосунок перевірити 0.1.30; нової дубльованої іконки «Джарвіс Тест» немає.
- [ ] У Pixel: Джарвіс → «Джарвіс — керування екраном» у Спеціальних можливостях увімкнено за власною згодою.
- [ ] Bluetooth/Wear OS Data Layer під'єднаний; телефонний супутник працює. «Примусово зупинити» в Android може припинити фонові служби.

## 1. Watch7 → Pixel, повторне прослуховування
- [ ] «Телефон» → «Відкрий YouTube»; дію виконує саме Pixel, годинник отримує відповідь.
- [ ] Після відповіді, БЕЗ додаткового натискання, «Натисни пошук» → «Назад» → «Постав гучність на 70».
- [ ] Кнопка/дотик до обличчя: перший запускає прослуховування, другий надсилає записану фразу.
- [ ] Після завершення голосової відповіді Джарвіс знову слухає; команди не дублюються.
- [ ] Вихід із «Телефон» повертає звичайний режим; мікрофон не записує без дозволу Android.

## 2. Керування жестами годинника
- [ ] Galaxy Watch7 → Налаштування → Кнопки та жести → Knock knock → відкриття «Джарвіс».
- [ ] У Джарвісі на годиннику: ⋮ → «Knock knock → мікрофон» → увімкнено; системний Knock knock запускає застосунок та мікрофон.
- [ ] За потреби: ⋮ → «Струс зап'ястя → мікрофон»; перший подвійний імпульс запускає, наступний завершує диктування.
- [ ] Звичайна ходьба не запускає мікрофон випадково; за наявності помилкових запусків вимкнути експериментальний струс.
- [ ] Системний Double pinch не оголошується підтримуваним без окремої Android інтеграції.

## 3. Bolt із голосової команди годинника
- [ ] «Таксі [адреса]» надходить з Watch7 до Pixel; відкривається ПАСАЖИРСЬКИЙ Bolt.
- [ ] Після відкриття програми Джарвіс **чекає видимого «Рушаймо»** (замість сліпого натискання через 4 секунди).
- [ ] Натискає «Рушаймо» ЛИШЕ на підтвердженому домашньому екрані Bolt; очікує появу «Маршрут».
- [ ] Натискає «Місце висадки», НЕ «Місце посадки».
- [ ] Записує адресу з команди в поле висадки та за можливості використовує Enter/Пошук.
- [ ] Не натискає «Замовити поїздку», не оплачує і не підтверджує без людини.
- [ ] Коли Bolt змінює верстку або не знаходить «Рушаймо», звітує про помилку, без випадкових дотиків.
- [ ] Повертає результат на годинник; нову команду можна сказати після завершення.

## 4. Spotify: плейлисти
- [ ] «Увімкни реп» → Spotify → Моя бібліотека → Пісні, що сподобалися → фільтр Реп → велика Play.
- [ ] «Увімкни укр муз» → Моя бібліотека → плейлист «Укр муз» → велика Play.
- [ ] «Увімкни плейлист [назва]» → Моя бібліотека → точна назва → сторінка плейлиста → велика Play; музика реально звучить на Pixel.
- [ ] Якщо кнопка Play — графічна без Accessibility-мітки, захищене емулювання працює тільки на підтвердженій сторінці плейлиста.
- [ ] Не натискає Shuffle замість Play і не ставить на Pause вже відтворювану музику.
- [ ] Якщо налаштований Spotify App Remote і збережений URI, використовує прямий запуск як пріоритетний.

## 5. Spotify: пісні UA / RU / EN і змішані команди
- [ ] «Увімкни пісню Плакала» — українська команда / українська назва.
- [ ] «Увімкни пісню Метель» — українська команда / російська назва.
- [ ] «Увімкни пісню Всё как у людей» — «е» / «ё» не ламає пошук.
- [ ] «Увімкни пісню Shape of You» — українська команда / англійська назва латиницею.
- [ ] «Увімкни пісню Billie Jean» — друга англомовна назва.
- [ ] «Умімкни пісню Shape of You» — варіант помилково розпізнаного керівного слова теж маршрутизується.
- [ ] Пошук проходить саме у Spotify → вкладка Пошук → введення назви → точний результат → відтворення, без обов'язкового збереження треку в «Моя бібліотека».
- [ ] Трек із іншою назвою / remix / live не обирається мовчки.
- [ ] У налаштуваннях Watch7 ⋮ → «Розпізнавання: Авто UA/RU/EN»; при збої розпізнавання перевірити окремо «Українська», «Російська», «Англійська».
- [ ] **Увага:** Android SpeechRecognizer може не підтримувати перемикання мов усередині фрази. CI перевіряє розбір отриманого тексту, НЕ реальне багатомовне STT на годиннику.

## 6. Контроль на збої й сумісність
- [ ] Відключити телефон під час команди: годинник показує помилку, не вдає успіх.
- [ ] Заблокувати Pixel: для екранних дій повідомляє про потребу розблокування; безпечні фонові команди не вимагають доступу до екрана.
- [ ] Якщо root/Magisk відсутній, не покладатися на root-розблокування телефона.
- [ ] Після перезапуску Pixel перевірити дозволи й прийом команд; повне «Force stop» неможливо надійно обійти стандартним Android API.
- [ ] Spotify Free може обмежувати вибір конкретної пісні; обов'язково перевірити фактичне відтворення.

**Результат:** позначай кожен пункт тільки після перевірки на Pixel 9 / Galaxy Watch7. CI «green» ≠ функціональна гарантія в зовнішніх застосунках.
