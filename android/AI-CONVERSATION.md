# JARVIS — довільна розмова з ШІ (0.1.6, вихідний код)

## Поведінка

- Команди телефону, нотаток, будильників, таймерів, програм, ліхтарика і музики й далі розбираються локально.
- Невідома звичайна фраза або привітання надсилається ШІ. Текст відповіді виводиться в діалог і за ввімкненої опції читається Android TTS.
- Під час запиту видно «Джарвіс думає…». Кожен наступний запит має короткий контекст попередньої бесіди (до 14 повідомлень). Контекст лише в оперативній пам'яті, не синхронізується і не передається додатковим стороннім застосункам.
- Команди «Очисти діалог», «Новий діалог» або кнопка «Очистити контекст ШІ» обнуляють пам'ять бесіди.
- За відсутності з'єднання Джарвіс пропонує налаштувати підключення, не вигадує ШІ-відповідей.

## Підключення

Потрібен особистий HTTPS-бекенд, наприклад з `server/jarvis-ai-worker/`.
Це окремий сервер: **не потрібно і не можна вводити OpenAI API key у Android.**
У застосунку натисни «ШІ — підключення» і введи:

1. URL `https://<your-worker>.workers.dev/chat`.
2. Окремий, довгий секретний код доступу `JARVIS_CLIENT_TOKEN`, який налаштований на сервері.

Код доступу локально шифрується через Android Keystore (AES-GCM). Він не включений у APK або GitHub. Після перевстановлення телефону може знадобитися повторно ввести код.

У Worker потрібно окремо встановити секрет `OPENAI_API_KEY`. Без цього сервер поверне помилку налаштування. Базова інтеграція не працює без розгорнутого сервера та доступу до OpenAI API.

## Конфіденційність і обмеження

Звичайні команди обробляються локально. Довільні запитання відправляються через інтернет на ваш сервер та до OpenAI, лише після налаштування. Не вводь конфіденційні дані без потреби. Для публічного застосунку потрібна окрема авторизація користувачів, обмеження запитів та захист витрат; цей прототип призначений для персонального використання.

## Тести без APK

```sh
javac -encoding UTF-8 -d /tmp/jarvis-ai-tests \
  android/app/src/main/java/com/andriy/jarvis/AiChatPolicy.java \
  android/app/src/test/java/com/andriy/jarvis/AiChatPolicyTest.java
java -cp /tmp/jarvis-ai-tests com.andriy.jarvis.AiChatPolicyTest
(cd server/jarvis-ai-worker && npm test)
```

Це не Android-компіляція. APK без окремої команди не збирається; функціональність слід перевірити на пристрої після налаштування сервера і окремої збірки.
