# Дімон 0.1.46 — чекліст Google Pixel

Підписаний тестовий APK. Версія **0.1.46**, versionCode **56**, пакет `com.andriy.jarvis.stable`. Встановлювати поверх наявної версії, не видаляти застосунок. Перед тестуванням JARVIS Finance зробити його резервну копію.

## Підготовка
- [ ] Оновлення встановлюється поверх 0.1.45 без помилки підпису та без втрати даних.
- [ ] Увімкнено доступи до мікрофона, спеціальних можливостей і фонової роботи.
- [ ] Дімон залишається доступним після відкриття інших застосунків.
- [ ] Журнал роботи відображає етапи Spotify `SPOTIFY_STAGE` і кінцеві `LOCAL_DONE`/`LOCAL_ERROR` для завершених асинхронних операцій.

## Spotify на Pixel
- [ ] «Увімкни пісню романтична» відкриває Spotify → Пошук → вводить назву → шукає.
- [ ] Вибирає **перший видимий результат**, навіть якщо він плейлист, а пісня з подібною назвою розташована нижче.
- [ ] Якщо це плейлист — відкриває його та натискає справжню кнопку **Play**, перевіряє Pause/ознаки запуску, не натискає мініпрогравач.
- [ ] Якщо це пісня — натискає першу пісню й перевіряє її назву в мініпрогравачі.
- [ ] «Не та пісня» / «Інша пісня» вибирає наступний результат того самого пошуку, не повертається до першого.
- [ ] Якщо вже відкрито вкладку Пошук, не натискає її повторно.
- [ ] «Увімкни плейлист [назва]» знаходить плейлист у Моїй бібліотеці та відтворює.
- [ ] «Увімкни реп» та назви українською, російською, англійською працюють.

## Bolt і загальні команди
- [ ] «Джарвіс таксі»: чекає завантаження Bolt; при іншому початковому екрані повертається у правильний стан.
- [ ] Натискає «Рушаймо», «Місце висадки», вводить адресу, підтверджує і вибирає перший відповідний результат.
- [ ] Не замовляє таксі без окремого підтвердження.
- [ ] Дімон може прийняти другу команду після першої, мікрофон працює, не лише анімується.
- [ ] Команди з Watch7 доходять на Pixel, де це передбачено сценарієм.
- [ ] Сповіщення про кроки виконання видно внизу екрана.

**Увага:** ці пункти призначені для фізичного тестування. Автоматична компіляція не підтверджує реальне натискання на Pixel.
