# JARVIS 0.1.33 — Чекліст №1: Менеджер фінансів

Дата вихідного коду: 15.11.2026. Джерело: `feature/finance-local-ledger` → `release/jarvis-0.1.33-finance`.

Легенда: [x] реалізовано у вихідному коді, [ ] потребує перевірки на Pixel/Watch7 або підключення зовнішньої служби. **Перевірена компіляція ≠ перевірена робота на пристрої.**

## Основні функції

- [x] Вкладки Фінансів: Огляд, Операції, План і Звіти; створення власних рахунків.
- [x] Витрати, доходи, чайові, повернення, перекази між своїми рахунками; відокремлені рухи активів від доходів.
- [x] Готівка/картки, залишки, історія записів, фільтр рахунку/категорії/типу/періоду/суми.
- [x] Звірка фактичного залишку сьогодні або на кінець обраного минулого дня; історія звірок збережена.
- [x] Місячні й тижневі бюджети, цілі, резервування коштів, борги та часткове повернення боргів.
- [x] Регулярні платежі щодня, щотижня, щомісяця й щороку; підтвердження перед списанням, скасування останнього проведення.
- [x] Окремий звіт по чайових за зміну: готівкові, безготівкові й погодинні.
- [x] Ручний обмін валют за фактичною отриманою сумою і комісією; окремі довідкові курси НБУ.
- [x] Ручні криптопозиції, угоди купівлі/продажу, журнал, комісії, оцінка FIFO та попередження про невідому початкову собівартість.
- [x] Оцінка активів, боргів і загального капіталу в гривнях з позначкою відсутніх курсів/цін.
- [x] Звіти за день/тиждень/місяць, графіки, бюджетні пороги, незвичні/дубльовані витрати та сценарії економії.
- [x] Голосові й текстові команди українською; розпізнавання сум цифрами і словами; поправки останньої операції.
- [x] Пакетний запис 2–5 витрат одним висловом, ідентифікатор кожної голосової команди для уникнення дублювань.
- [x] Голосове уточнення: не вистачає суми — питає суму; не вистачає категорії — питає категорію.
- [x] Запити голосом: баланс, витрати, доходи, чайові, платежі, бюджети, криптоісторія й капітал.
- [x] Приймання команд на Pixel із Galaxy Watch7 і захищена черга до 20 записів із повторним відправленням.
- [x] Нагадування, тихі години, щотижневі й щомісячні підсумки (за бажанням), нейтральні сповіщення на заблокованому екрані.
- [x] Зашифрована SQLCipher v6 база з Android Keystore, механізм міграції старої бази.
- [x] Захищений екран фінансів, парольні JFB v6 резервні копії, відновлення зі старих JFB, CSV-експорт.

## Обов'язкова перевірка після встановлення

- [ ] Запуск Фінансів, створення й збереження двох рахунків, перезапуск застосунку.
- [ ] Один дохід, одна витрата, повернення, переказ; звірка залишку на сьогодні і в минулому.
- [ ] Фінансові голосові команди та уточнення на Pixel.
- [ ] Команда з Watch7 на Pixel, отримання відповіді, захист від подвійного запису при повторі.
- [ ] Робота годинника після закриття інтерфейсу й перезапуску, зі сплячим екраном і енергозбереженням (Android може відкладати фонове завдання).
- [ ] Експорт JFB, відновлення, хибний пароль, перевірка старих JFB, зміна пристрою.
- [ ] Міграція з попередньої фінансової бази без втрати даних.
- [ ] Баланс після обміну валют і після кількох криптоугод.
- [ ] Графіки, бюджетні пороги, сповіщення, PIN/захист екрана.

## Свідомо не включено

- [ ] Автоматичне читання банківських рахунків через Open Banking — потрібна інтеграція та дозвіл.
- [ ] Автоматичний крипторинок і торгові ордери — немає підключеного провайдера.
- [ ] Безмежний ШІ для будь-яких фінансових дій; небезпечні списання не підтверджуються навмання.
- [ ] Синхронізація двох незалежно редагованих телефонів; головна фінансова база одна — Pixel.

Цей чекліст описує функції в коді **кандидата 0.1.33**, не підтверджує їх роботу на пристроях.
