# JARVIS 0.1.35 — Watch7 / Pixel таймер: чекліст

Основа: **JARVIS 0.1.34 signed** + вибіркове виправлення Watch7-таймера.
Пакет `com.andriy.jarvis.stable`, code 45, оригінальний підпис — перевіряється CI.
Повний JARVIS Finance, Bolt і Spotify з релізу 0.1.34 зберігаються.
**На реальних Pixel і Galaxy Watch7 не перевірено автоматично.**

## Що виправлено

- Команда `Постав таймер на 1 хвилину` обробляється прямо на Watch7.
- Підтримується вимовлене `Постав таймер на одну хвилину` і `Постав таймер на хвилину`.
- З годинника на телефон відправляється точна кількість секунд (60), окремим Wear Data Layer action `set_timer`, без ШІ та Accessibility.
- Телефон перевіряє тривалість, доступ до точних будильників і відповідь AlarmManager.
- Годинник відображає/озвучує підтвердження **після** фактичної постановки таймера на Pixel.
- За відсутності дозволу **не видає удаваного успіху**, а пояснює, як його увімкнути.
- При недоступному Pixel повідомляє про втрату з'єднання, не підміняє локальним таймером.
- Підтримано виклик із увімкненим і вимкненим режимом «Телефон» без запуску сторонніх програм.

## Pixel — до тесту

- [ ] Перед оновленням зроблено резервну копію JARVIS Finance; стара програма НЕ видалена.
- [ ] На Pixel встановлено 0.1.35, номер версії та підпис сумісний.
- [ ] Налаштування → Програми → Спеціальний доступ → Будильники й нагадування → Джарвіс → Дозволити.
- [ ] Налаштування → Сповіщення → Джарвіс → Дозволити.
- [ ] Під час прямої команди `Постав таймер на 1 хвилину` Pixel приймає 60 секунд.
- [ ] Через 60 секунд є сигнал/вібрація/сповіщення Pixel згідно з поточними дозволами.
- [ ] `Скасуй таймер` скасовує активний таймер.
- [ ] Без дозволу точних будильників відповідь містить конкретну інструкцію; таймер не вважається створеним.

## Galaxy Watch7

- [ ] На годиннику той самий підписаний 0.1.35, з'єднання з Pixel активне.
- [ ] `Постав таймер на 1 хвилину` → годинник показує «Передаю таймер на Pixel…», потім підтверджує 60 секунд.
- [ ] `Постав таймер на одну хвилину` → такий самий результат.
- [ ] `Постав таймер на хвилину` → такий самий результат.
- [ ] `Постав таймер на дві хвилини` → 120 секунд.
- [ ] Команда при активному режимі «Телефон» не перетворюється на натискання екрана.
- [ ] При вимкненому Bluetooth і Wi-Fi на годиннику Джарвіс повідомляє про відсутність Pixel.
- [ ] Після відповіді Джарвіс на годиннику залишається відкритим.
- [ ] `Постав будильник на 07:30` лишився працездатним і не плутається з таймером.

## Регресія після оновлення

- [ ] Bolt: `таксі до [адреса]` — відкриває Bolt; без автоматичного підтвердження оплати/поїздки.
- [ ] Spotify: `увімкни пісню`, `увімкни плейлист`, `увімкни реп` — перевірити на екрані Pixel.
- [ ] JARVIS Finance: `витратив 150 готівка транспорт таксі` і `заробив 350 готівка чайові столик 5`; старі рахунки й записи збереглися.
- [ ] Примітки, бюджети, сповіщення, фоновий режим та передача команди з Watch7 не регресували.

Таймер **запускається на Pixel**, а не на самому Watch7. Для локальної вібрації Watch7 потрібен окремий режим локального годинникового таймера.
