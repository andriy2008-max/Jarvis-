# Дімон 0.1.43 — Galaxy Watch7 QA

Версія 0.1.43, versionCode 53, оригінальний стабільний підпис.

## Виправлено
- Попередні виправлення стабільності Watch7, мікрофона, Spotify Home/свайпу/плейлистів, Google Карт збережено.
- «Увімкни пісню [назва]» залишає номер натиснутого результату тільки в локальній пам'яті годинника.
- «Інша пісня» / «Не та пісня» сказані на годиннику виконуються на Watch7, НЕ передаються на телефон або ШІ.
- Для наступної пісні Дімон повторно відкриває вихідний пошук Spotify й намагається натиснути наступний рядок списку за доступними мітками пісні та позицією.
- Watch7 НЕ використовує координату Pixel. Якщо рядок не вдається підтвердити протягом 11 с, повідомляє про невдачу замість випадкового натискання.

## Ручний чек-лист Watch7
- [ ] Десять команд поспіль без аварійного закриття та повернення до циферблата.
- [ ] Мікрофон слухає другу команду, навіть із Bluetooth-навушниками.
- [ ] «Увімкни пісню Мама» відкриває Spotify на годиннику й вибирає результат.
- [ ] «Інша пісня» вибирає другий доступний рядок ПОШУКУ НА ГОДИННИКУ.
- [ ] «Не та пісня» вибирає наступний, третій рядок за доступними Accessibility-даними.
- [ ] Якщо пошук/список недоступні, команда повертає зрозуміле повідомлення, не натискає випадкових кнопок.
- [ ] Після нової назви пісні вибір починається спочатку.
- [ ] «Увімкни плейлист…» — Home, свайп угору, пошук назви в бібліотеці, відтворення.
- [ ] «Де я» — карта; «Знайди дорогу до…» — вибір способу пересування внизу Watch7.
- [ ] Дімон залишається доступним після виконання кожної команди.

Примітка: кількість доступних наступних результатів залежить від реального дерева Accessibility Spotify Wear. Емулятор не може підтвердити роботу Spotify у вашому акаунті.
