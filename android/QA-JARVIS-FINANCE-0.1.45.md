# JARVIS Finance 0.1.45 — фінансовий чекліст

**Відновлений вбудований модуль**, не сторонній Money Manager. Дані зберігаються на Pixel у власній зашифрованій базі SQLCipher. Не видаляти APK перед оновленням.

## Відкриття і рахунки
- [ ] Головне меню містить «💰 JARVIS Finance», старого «Менеджер фінансів · API» немає.
- [ ] Відкриваються вкладки «Огляд», «Операції», «План», «Звіти».
- [ ] Створюється рахунок «Готівка» в UAH із початковим залишком.
- [ ] Створюється другий рахунок «Mono», суми показуються окремо.
- [ ] Переказ між рахунками змінює залишки правильно, але не вважається доходом.
- [ ] Редагування транзакції й її скасування не дублюють проведення.

## Голосові команди
- [ ] На Pixel: «Витратив 150 готівка транспорт таксі» додає витрату -150.
- [ ] На Pixel: «Заробив 350 готівка чайові столик 5» додає дохід +350.
- [ ] «Баланс рахунків» повертає актуальний залишок.
- [ ] «Скільки витратив сьогодні» збігається з операціями у журналі.
- [ ] «Встанови бюджет 2000 на транспорт» і «Залишок бюджету» працюють для вибраного періоду.
- [ ] «Не 150, а 180» коригує потрібний попередній запис, не створює додаткову витрату.
- [ ] Watch7 передає команду Pixel, показує підтвердження, повторна доставка не призводить до подвійного запису.
- [ ] Фінансовий запит із заблокованого телефона не показує приховані дані, якщо це заборонено у налаштуваннях.

## Планування і звіти
- [ ] Тижневий і місячний бюджети правильно підраховують залишок.
- [ ] Цілі, борги, регулярні платежі й виконання планів показують коректні суми.
- [ ] Категорії, дати і валюти у звітах збігаються з журналом.
- [ ] CSV-експорт відкривається в таблицях.
- [ ] Зашифрована резервна копія створюється та може бути відновлена за паролем.
- [ ] Неправильний пароль не змінює наявні фінансові дані.
- [ ] Повторний запуск/оновлення 0.1.45 не очищує історію.

### Статус
Пройдені автоматичні тести фінансової схеми і парсера; поведінка в реальному застосунку ще потребує перевірки.

## Додаткова перевірка 0.1.45 — збереження команд Watch7
- [ ] За тимчасової помилки бази або зв'язку Pixel запис не видаляється з черги Watch7.
- [ ] Після відновлення зв'язку команда повторюється зі старим ID; журнал Pixel містить рівно одну транзакцію.
- [ ] Нерозпізнана фінансова команда відхиляється без списання грошей.
- [ ] Після оновлення поверх 0.1.44 залишилися рахунки, записи, резервні копії та ключі Android Keystore.
