# JARVIS — Spotify App Remote + Mobilerun Portal (незібрані зміни після 0.1.35)

## Статус і межі
- Код у гілці `feature/spotify-portal-ui-v0.1.35`, на основі `fix/watch-local-timer-v0.1.35`: збережено локальний таймер Watch7, повний JARVIS Finance, Bolt/Spotify 0.1.35.
- **APK не зібрано**. GitHub CI перевіряє компіляцію Android та голосові тести. Перевірка на Pixel/Watch7 потрібна після дозволеної збірки.
- Власний `ScreenControlAccessibilityService` Джарвіса залишається основним. Portal встановлюється окремо, підключається **виключно за згодою власника**, а не копіюється в застосунок (Portal AGPLv3).
- Portal не передає дані в ШІ через нашу інтеграцію. JARVIS використовує тільки `http://127.0.0.1:8080/state` (читання) і `/tap` (натискання) з локальним bearer-токеном, без автоматичного вмикання хмарних функцій.

## 1. Підключити Spotify на Pixel
1. Відкрити в JARVIS: **🎵 Spotify · прямий запуск**.
2. Створити/налаштувати власний застосунок у https://developer.spotify.com/dashboard (Spotify Developer).
3. Указати пакет `com.andriy.jarvis.stable`, SHA-1 показаний у налаштуваннях JARVIS, і Redirect URI, також показаний там.
4. Скопіювати Spotify Client ID у JARVIS. Не вводити Client Secret.
5. Натиснути **Підключити / перевірити Spotify**, надати дозвіл у Spotify.
6. Додати точні відповідності `Назва | Посилання Spotify`, наприклад:
   - `Workout | https://open.spotify.com/playlist/[ваш-id]`
   - `Реп | https://open.spotify.com/playlist/[ваш-id]` (лише якщо потрібен саме окремий плейлист Реп)
   - `Моя пісня | https://open.spotify.com/track/[ваш-id]`
7. `Увімкни плейлист Workout` → спочатку App Remote URI, потім перевірка `PlayerState`.
8. `Увімкни пісню Моя пісня` → App Remote URI, якщо URI збережено. Для запуску конкретного треку потрібні права Spotify Premium.
9. Якщо URI/Client ID/авторизація недоступні, старий режим керування інтерфейсом Spotify збережено. Команда `Увімкни пісню [довільна назва]` без збереженого URI як і раніше використовує пошук по екрану. API пошуку за вільним текстом **не підключено**.

## 2. Підключити Mobilerun Portal на Pixel
1. Встановити Mobilerun Portal із https://github.com/droidrun/mobilerun-portal/releases (окремий APK).
2. Android → Спеціальні можливості → увімкнути **Mobilerun Portal**. Власну службу Джарвіса не вимикати.
3. У Mobilerun Portal увімкнути **Local HTTP Server**, порт `8080`. Копіювати auth token **з головного екрана Portal**, не ділитися ним.
4. У JARVIS Pixel відкрити **👁 Mobilerun Portal · елементи екрана**.
5. Вставити токен, ввімкнути «Дозволити Джарвісу використовувати локальний Portal», натиснути **Зберегти**.
6. Відкрити Bolt або Spotify й натиснути **Перевірити зчитування елементів**; має з'явитися назва пакета й кількість елементів.
7. Reverse/Cloud Connection у Portal **залишити вимкненим**. Доступ тільки localhost 127.0.0.1, зовнішні HTTP-адреси заборонені мережевими правилами JARVIS.
8. Для відключення: у тому ж екрані натиснути **Вимкнути й видалити токен**. Токен у JARVIS зберігається зашифрованим через Android Keystore.

## 3. Bolt — контролювати кроки
- [ ] «Таксі до [адреса]» відкриває Bolt на Pixel.
- [ ] Через 4 секунди JARVIS перевіряє foreground-пакет Bolt.
- [ ] За увімкненого Portal читає `/state` та шукає `Рушаймо` за точним текстом і межами екрана, натискає через `/tap`.
- [ ] Якщо кнопки немає, повторює читання кожні 2 секунди; після обмеженого часу переходить до попереднього каліброваного сценарію лише якщо ще не було неоднозначного натискання.
- [ ] Після підтвердженого натискання `Рушаймо` шукає `Місце висадки` через Portal; без підтвердження не натискає резервні координати на невідомій сторінці.
- [ ] Введення адреси й Enter продовжують працювати через власну службу Джарвіса.
- [ ] **Не підтверджує та не оплачує поїздку**.
- [ ] При вимкненому Portal залишається попередній алгоритм Bolt 0.1.35.

## 4. Spotify — робочі команди
- [ ] `увімкни плейлист [збережена назва]` → App Remote за URI без Play.
- [ ] `увімкни пісню [збережена назва]` → App Remote за URI; PlayerState показує трек.
- [ ] `увімкни пісню [незбережена назва]` → старий UI-пошук/Enter/вибір пісні.
- [ ] `увімкни реп` → за наявності окремого URI «Реп» прямий плейлист; інакше «Моя бібліотека» → «Пісні, що сподобалися» → фільтр «Реп».
- [ ] Коли native Accessibility не знаходить таб «Пошук» або «Моя бібліотека», Portal може один раз натиснути **точно розпізнаний** таб, а не випадкові координати.
- [ ] При вимкненому Portal усе працює як до додаткового підключення.
- [ ] Після команди Джарвіс на Watch7 не закривається; статус повертається з Pixel.

## 5. Інші функції/регресія
- [ ] Локальний таймер «Постав таймер на 1 хвилину» сказаний Watch7 запускається саме на Watch7.
- [ ] Витрати, доходи, примітки, баланси та бюджети JARVIS Finance збережені.
- [ ] Сповіщення кроків, режим «Телефон», плаваюче обличчя й голос не регресували.
- [ ] При відключенні Bluetooth передача Spotify/Bolt має помітно повідомляти про відсутність Pixel.
- [ ] Без увімкненої спеціальної можливості Android ніяких прихованих натискань не робить.

## Важливі обмеження
- Потрібні ручне встановлення/дозволи Portal та Spotify Developer Client ID (і згода Spotify). Без них підключення **не активне**.
- Mobilerun Portal як окрема програма має AGPLv3; інтеграція в JARVIS використовує документований HTTP API без включення чужого коду.
- Прийнятий Portal `tap` — це підтвердження відправлення дотику, а не гарантоване завантаження наступної сторінки.
- Ліцензії та умови Spotify потрібно дотримуватися при поширенні додатка.
