# QA — Watch7 Google Maps: короткий свайп угору + «Пішки»

Цей чекліст для перевірки **на годиннику** після наступної збірки. Сам APK наразі не збирається.

## Команда «Знайди дорогу до…»
- [ ] Відкрити Google Maps без переходу на Pixel
- [ ] Ввести адресу та натиснути пошук
- [ ] Натиснути на відповідний результат адреси
- [ ] Дочекатися маршрутів; на деяких версіях Maps Android не віддає підписи елементів Accessibility
- [ ] Виконати **один короткий свайп угору** (від 75% до 55% висоти циферблата)
- [ ] **Після свайпу** натиснути картку пішохода між громадським транспортом і велосипедом
- [ ] Якщо іконку видно Android — натиснути реальний елемент або його клікабельного батька
- [ ] Якщо підписи не видно Android — резервна точка після свайпу біля 45% висоти, а не старі 84% на велосипед
- [ ] Не натискати «Пішки» до свайпу; не натискати нічого за відкритої клавіатури
- [ ] Якщо маршрут відкрився — не робити повторний свайп чи повторне натискання

## Регресії
- [ ] Варіант із двома тривалостями маршрутів + велосипед без тривалості
- [ ] Варіант лише з однією тривалістю та відстанню «21 км»
- [ ] Варіант без доступних підписів: після вибору адреси зачекати 2,4 с, потім короткий свайп
- [ ] Повільний інтернет — жести виконуються лише після вибору адреси й очікування
- [ ] З відкритою клавіатурою Maps маршрут не натискається
- [ ] Команда «Знайди моє місце» не змінена
- [ ] Spotify Watch7 зберігає тільки свайпи вниз; Bolt і JARVIS Finance не змінені

Автоматична компіляція перевіряє лише код. Реальну точність тапу на Watch7 підтверджує користувач.
