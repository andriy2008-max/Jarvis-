# JARVIS 0.1.35 — регресійний чекліст після оновлення до 0.1.36

**Історична відмінність:** в опублікованому APK **0.1.35** таймер, продиктований Watch7, встановлювався **на Pixel**. Після запиту власника **в 0.1.36 змінено поведінку**: таймер годинника тепер локальний; на телефоні — телефонний. Нижче перевіряємо, щоб розпізнавання з 0.1.35 збереглося і нове правило місця виконання працювало.

## Голосові фрази
- [ ] «Постав таймер на 1 хвилину» → 60 секунд.
- [ ] «Постав таймер на одну хвилину» → 60 секунд.
- [ ] «Постав таймер на хвилину» → 60 секунд.
- [ ] «Постав таймер на дві хвилини» → 120 секунд.
- [ ] «Постав таймер на 4 хвилини» → 240 секунд.
- [ ] «Постав таймер без часу» → повідомлення про невірний час, без запуску.
- [ ] Тривалість понад 3 години відхиляється.
- [ ] Помилка відсутності дозволу «Будильники й нагадування» чітко озвучується або показується на пристрої.

## Pixel
- [ ] Таймер сказаний Pixel запускається на Pixel; підтверджується залишок часу.
- [ ] Через 60 секунд сигнал/вібрація працює на телефоні за системних дозволів.
- [ ] «Скасуй таймер» на Pixel скасовує **лише телефонний** таймер.
- [ ] Під час заблокованого екрана / згорнутого Джарвіса таймер не губиться.
- [ ] Відсутність сповіщень не приховується під удаваним підтвердженням.

## Watch7 (оновлена логіка 0.1.36)
- [ ] Під час відсутності зв'язку з Pixel «Постав таймер на 1 хвилину» запускає **локальний таймер годинника**.
- [ ] Через 60 секунд годинник сигналізує/вібрує згідно з дозволами Wear OS.
- [ ] «Скільки часу на таймері?» відповідає з годинника, а не з Pixel.
- [ ] «Скасуй таймер» скасовує локальний годинниковий таймер, не телефонний.
- [ ] «Постав будильник на 07:30» обробляється окремо від таймера.
- [ ] Голосова відповідь після таймера не закриває головний екран Джарвіса.

**Особливість:** нині один активний таймер Джарвіса на кожному пристрої; новий замінює попередній.
