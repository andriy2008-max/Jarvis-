# Дімон 0.1.46 — чекліст Galaxy Watch7

Встановити **той самий підписаний APK** на Galaxy Watch7 та Pixel, поверх попередньої версії. Всі дії Spotify, озвучені годиннику, виконуються саме на годиннику.

## Spotify: ТІЛЬКИ вниз
- [ ] «Увімкни пісню [назва]» відкриває Spotify на Watch7.
- [ ] Якщо іконка пошуку вже видима — натискає її **без жодного свайпу**.
- [ ] Якщо пошуку немає — робить **довгий свайп униз**, потім перевіряє наявність пошуку.
- [ ] За потреби виконує до **трьох свайпів униз загалом**. **Жодного свайпу вправо чи вгору** під час сценаріїв Spotify.
- [ ] Вводить назву, вибирає перший результат. Якщо плейлист — відкриває та натискає **Play**.
- [ ] Після Play не свайпає вправо, повертається до Дімона та повторно вмикає мікрофон.
- [ ] «Не та пісня» / «Інша пісня» переходить до другого, третього тощо результату; не вибирає перший повторно.
- [ ] «Увімкни плейлист [назва]» шукає плейлист у Моїй бібліотеці й натискає Play.
- [ ] Spotify залишається відтворювати, коли Дімон знову слухає команди.

## Google Maps: короткий свайп УГОРУ (це ОКРЕМА команда, не Spotify)
- [ ] «Знайди дорогу до [адреса]» відкриває Google Maps **на Watch7**.
- [ ] Вводить адресу, натискає пошук, вибирає перший відповідний результат.
- [ ] Чекає завантаження екрану маршрутів, навіть якщо Maps приховав їхні підписи від Accessibility.
- [ ] Виконує **один короткий свайп угору**, приблизно від 75% до 55% висоти годинника.
- [ ] Натискає **картку «Пішки» з іконкою пішохода**, розташовану між громадським транспортом і велосипедом. Не вибирає велосипед.
- [ ] Якщо Maps приховав підписи, використовує контрольоване резервне натискання після свайпу, не під час клавіатури.
- [ ] «Де я зараз» продовжує працювати без регресій.

## Watch7 ↔ Pixel
- [ ] Дімон не закривається після виконання першої команди, готовий до другої.
- [ ] Голос і текст відповіді доступні на годиннику; анімація відповідає реальному мікрофону.
- [ ] «Телефон» передає команди через Wear Data Layer на Pixel.
- [ ] Таймер, будильник та фінансові команди передаються на правильний пристрій.
- [ ] Витрата з Watch7 записується на Pixel **один раз**, повторне доставлення не створює дубль.

Це чекліст для реального Watch7; компіляція та контрактні тести не підтверджують фізичну роботу Spotify чи Maps.
