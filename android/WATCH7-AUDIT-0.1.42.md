# Дімон 0.1.42 — перевірка збірки Pixel + Watch7

## Зміна
Критична помилка Pixel Spotify за скриншотом користувача: рядок «Що ви хочете послухати?» візуально відкритий, але його не вдавалося натиснути. У 0.1.42 після спроби Accessibility додано контрольоване натискання на відносній координаті Pixel 50% ширини × 17,5% висоти дисплея; лише у Spotify, максимум двічі, з перевіркою відкриття редактора перед вводом тексту. На Watch7 телефонна координата не застосовується.

## Перевірки GitHub Actions
- Java regression contracts, зокрема `SpotifyTrackSearchRulesTest`.
- Android debug compile та AndroidTest package.
- Синтетичні тести життєвого циклу на Wear OS емуляторі.
- Signed `assembleRelease` оригінальним JARVIS сертифікатом.
- Перевірка пакету `com.andriy.jarvis.stable`, versionCode 52, versionName 0.1.42, сертифікату SHA-256 та контрольної суми APK.

## Важливі застереження
Ці автоматичні перевірки не імітують Spotify саме на фізичному Pixel і не гарантують, що після жесту відкриється клавіатура, а також не підтверджують фактичний звук на Watch7. Окремі чек-листи: `QA-DIMON-0.1.42-PIXEL.md` і `QA-DIMON-0.1.42-WATCH7.md`. APK є тестовим кандидатом, не позначати як повністю перевірений реліз.
