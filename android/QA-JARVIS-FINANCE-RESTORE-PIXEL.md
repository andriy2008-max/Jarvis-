# JARVIS Finance — відновлення на Google Pixel

**Гілка:** `feature/restore-jarvis-finance`. **Статус:** код відновлено; фактичні тести на Pixel і стабільний APK не виконані.

## Основні зміни

- Кнопка `💰 Менеджер фінансів · API` замінена на `💰 JARVIS Finance`.
- Видалено екран і вихідні класи зовнішнього Money Manager API.
- Власна база `jarvis-finance-secure.db` зашифрована SQLCipher і ключем Android Keystore.
- Чотири вкладки: **Огляд**, **Операції**, **План**, **Звіти**.
- Рахунки, категорії, витрати/доходи, чайові, зміни, перекази, борги,
  цілі, резерви, бюджети, звіти, графіки, зашифровані резервні копії.
- Голосові транзакції НЕ запускають Money Manager, стороннє API чи Accessibility.
- Зміни не змінюють package name/підпис, не видаляють попередню базу і не очищують налаштування.
- Бюджети поточного місяця з попередньої спрощеної системи безпечно імпортуються в журнал;
  старі значення залишаються неторканими, наявні плани не перезаписуються.

## Голосові команди Pixel — перевірити вручну

- [ ] `Відкрий фінанси` — відкриває JARVIS Finance.
- [ ] `Витратив 150 готівка транспорт таксі до роботи` — створює ОДНУ витрату:
  сума 150 UAH, рахунок готівка, категорія Транспорт, примітка «таксі до роботи».
- [ ] `Потратив 50 моно транспорт автобус` — витрата 50 UAH на карту моно, примітка «автобус».
- [ ] `Витратив 12,50 карта моно харчування кава` — витрата 12,50 UAH, категорія Харчування.
- [ ] `Заробив 350 готівка чайові столик п'ять` — дохід 350 UAH, категорія чай, примітка.
- [ ] `Дімон, заробив 15000 моно зарплата за листопад` — дохід 15000 UAH, категорія Зарплата.
- [ ] `Витрата кава 85` — збереження через стандартний рахунок, якщо він вибраний.
- [ ] `Не 85, а 95` — виправлення останньої дозволеної операції без дублювання.
- [ ] `Встанови бюджет 15000 гривень на місяць` — встановлює бюджет у власній базі.
- [ ] `Встанови бюджет на транспорт 2000 грн` — оновлює категорію без другого однакового плану.
- [ ] `Покажи бюджет на транспорт` і `Залишок бюджету` — власні обліковані суми.
- [ ] `Баланс рахунків`, `Який баланс?` — дійсні залишки або «невідомо», без вигаданих цифр.
- [ ] `Скільки я витратив сьогодні?`, `Скільки витратив цього місяця?` — звіт з власних операцій.
- [ ] `Фінансовий звіт`, `Звіти`, `Скільки чайових за зміну?` — власні дані й звіти.
- [ ] `Портатив 90 готівка транспорт` і `переказ 1000 мамі` не створюють випадкових витрат.
- [ ] Відсутній рахунок або невідома категорія — без запису та з поясненням.
- [ ] Перевірити другу команду після першої, швидкі повторення, блокування екрана та повернення з фону.
