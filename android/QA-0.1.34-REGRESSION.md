# JARVIS 0.1.34 — регресійний чекліст після оновлення до 0.1.36

Цей розділ перевіряє можливості, введені у 0.1.34, **у новому APK 0.1.36**. Живе виконання команд на Pixel і Galaxy Watch7 має підтвердити користувач; CI перевіряє код.

## Підготовка Pixel
- [ ] Установити 0.1.36 ПОВЕРХ попереднього стабільного Джарвіса без видалення застосунку.
- [ ] Перед оновленням зберегти резервну копію JARVIS Finance.
- [ ] На Pixel ввімкнути «Джарвіс — керування екраном» у Спеціальних можливостях.
- [ ] Дозволити сповіщення та точні будильники, якщо використовуються таймери.

## Bolt (фікс помилки UnsupportedOperationException)
- [ ] Голосом на Watch7 сказати: «Таксі до Львів, площа Ринок, 1»; Bolt відкривається **на Pixel**, Watch7 залишається з Джарвісом.
- [ ] Після завантаження Bolt натискається «Рушаймо», без помилки `TAP_RUSHAYMO_PREP (UnsupportedOperationException)`.
- [ ] На наступному екрані відкривається «Місце висадки»; адреса вводиться рівно один раз, потім Enter.
- [ ] Джарвіс показує проміжні повідомлення про дії; помилки повідомляє без довільних повторних натискань.
- [ ] Результати адреси видно; **замовлення/оплата поїздки без підтвердження не виконуються**.
- [ ] Якщо кнопка не знайдена, алгоритм обмежено чекає, не натискає чужу програму.

## Spotify
- [ ] «Увімкни пісню [назва]» → Spotify → Пошук → текст → Enter → рядок пісні.
- [ ] Якщо «Пошук» уже відкрито, зайвого переходу немає; друга спроба тільки після перевірки стану.
- [ ] «Увімкни плейлист [назва]» → «Моя бібліотека» → правильний плейлист → пісня зі списку, не випадкова зелена кнопка.
- [ ] «Увімкни реп» → «Пісні, що сподобалися» → фільтр «Реп» → пісня зі списку.
- [ ] Українська, російська й англійська назви пісень не губляться при введенні.
- [ ] Помилки Spotify не закривають Джарвіса на годиннику.

## JARVIS Finance
- [ ] Після оновлення збережені всі рахунки, транзакції, бюджети й історія.
- [ ] «Витратив 150 готівка транспорт таксі» → витрата 150 ₴ із приміткою «таксі».
- [ ] «Потратив 50 моно транспорт автобус» → рахунок «карта моно» і примітка.
- [ ] «Заробив 350 готівка чайові столик 5» → дохід 350 ₴ і примітка «столик 5».
- [ ] Старі фрази «запиши витрату…», «витратив 150 на каву позавчора» далі працюють.
- [ ] Запит про баланс, витрати за сьогодні, бюджет читає власну захищену базу, не сторонній менеджер.
- [ ] Те саме фінансове повідомлення з Watch7 створює **один** запис на Pixel.
- [ ] «Портатив…» не записує нічого.

Статус: автоматична компіляція / тести — через GitHub Actions 0.1.36; живі тести — не виконано.
