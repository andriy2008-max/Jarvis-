# Дімон 0.1.41 — Galaxy Watch7 SM-L310: ручний чек-лист

**Статус: тестовий реліз 0.1.41, versionCode 51.** Гарантується лише автоматична перевірка там, де CI завершився успішно. Це НЕ звіт про пройдені фізичні тести.

Телефон: Google Pixel 9; годинник: Galaxy Watch7 без root. Android package при оновленні: `com.andriy.jarvis.stable`. Встановлювати APK **поверх** 0.1.40, не видаляти Дімон (щоб зберегти дані). Дозволи мікрофона та сповіщень, Wear Accessibility, з'єднання з Pixel перевірити окремо.

## Критичні тести Watch7
- [ ] Відкрити Дімона, сказати 20 різних команд поспіль; після кожної він не завершується аварійно й може знову слухати.
- [ ] Відкрити Spotify/Карти, повернутися до Дімона; жодного незапланованого повернення на циферблат.
- [ ] Дозволити мікрофон; 10 послідовних команд без гарнітури; 10 із Bluetooth-навушниками: має використовуватися вбудований мікрофон Watch7, без помилкового раннього вимкнення.
- [ ] Під час слухання приєднати/від'єднати навушники. Перевірити затримку першого слухання, паузу після фрази й повторне слухання.
- [ ] «Скажи привіт»: TTS відповідає; індикація «вухо + рука» відповідає реальному слуханню.
- [ ] «Телефон»: команда до Pixel, одна дія без дублювання, результат повернувся на Watch7.
- [ ] Від'єднати Pixel: Дімон не падає, дає помилку зв'язку; після повернення зв'язку наступна команда працює.
- [ ] «Постав таймер на 1 хвилину», «Постав будильник»: перевірити виконання на призначеному пристрої, не лише повідомлення.

## Spotify на Watch7
- [ ] «Відкрий Spotify» без слова «Дімон»: Spotify стартує на годиннику.
- [ ] «Увімкни пісню Пачка сигарет» із відкритого плеєра: перевірка Home → свайп вправо за потреби → довгий свайп угору → Пошук → поле → ввід назви → Enter → потрібна пісня → звукове відтворення.
- [ ] Повторити з відкритою клавіатурою Spotify; вона не перешкоджає поверненню до Home.
- [ ] Назви пісень українською, російською й англійською; перевірити фактичне відтворення та наступну голосову команду.
- [ ] «Увімкни плейлист [назва]»: Home → довгий свайп угору → відшукати точну назву в списку БЕЗ переходу до глобального Search → відкрити → Play.
- [ ] Плейлист нижче по списку: повторні свайпи униз і пошук; відсутній плейлист: контрольоване завершення без циклу.
- [ ] «Увімкни реп», «Увімкни українське», «Увімкни музику» — правильна вкладка, без дублювання свайпів і натискань.
- [ ] Spotify не отримує жодних координат Pixel; відсутність потрібної кнопки повертає помилку.

## Google Карти на Watch7
- [ ] «Де я» із початкового екрана Карт: натискається верхня ліва кнопка зі складеною картою, потім показ поточного місця.
- [ ] «Де я» коли сама карта вже відкрита: зайвого натискання початкової кнопки немає.
- [ ] «Знайди дорогу до [адреса]»: пошук, вибір місця, маршрут, «Пішки» за Accessibility; якщо кнопка невидима, одне натискання **внизу посередині** (50% ширини / 88% висоти Watch7) тільки на екрані маршруту.
- [ ] Перевірити, чи саме потрібну кнопку режиму пересування було натиснуто, а не навігацію; повторити з іншим маршрутом.
- [ ] Не натискає по низу екрана під час клавіатури, діалогу або початкової сторінки Карт.

## Інше / діагностика
- [ ] Нотатки, відповіді ШІ, результати з Pixel, голосове озвучення.
- [ ] Коли повториться збій: ⋮ → Діагностика → Журнал роботи → Скопіювати/Поділитися; записати команду та час.
- [ ] Перевірити обмеження енергозбереження, перемикання застосунків і фонове відновлення.

**Якщо фізичний тест не пройдено, не позначати пункт завершеним.** Android/Wear OS не гарантує постійної роботи мікрофона у фоні. Голосовий сервіс SpeechRecognizer може ігнорувати запит маршруту мікрофона; навушники — окремий тест.
