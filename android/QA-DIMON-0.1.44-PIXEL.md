Версія: 0.1.44, versionCode 54. Встановлювати поверх чинного застосунку, **не видаляти** його перед оновленням. APK має оригінальний сертифікат та package com.andriy.jarvis.stable.

## Підготовка
- [ ] Створити резервну копію важливих даних Finance через інтерфейс, якщо база вже використовується.
- [ ] Встановити оновлення поверх старої збірки без скидання даних.
- [ ] Перевірити наявність доступів до мікрофона, служби спеціальних можливостей і роботи у фоні.
- [ ] Перевірити, що версія 0.1.44 і меню не містить «Менеджер фінансів · API».

## Spotify на телефоні
- [ ] «Відкрий Spotify»: Дімон не закривається, зберігає керування.
- [ ] «Увімкни пісню [назва]»: відкриває Пошук, фокусується на полі, вводить текст, обирає першу відповідну ПІСНЮ, запускає відтворення.
- [ ] Якщо вже відкрито вкладку Пошук, не натискає вкладку вдруге.
- [ ] «Інша пісня» / «Не та пісня»: обирає наступний результат того самого пошуку, без повторного введення назви.
- [ ] Повторна команда «Інша пісня» переходить ще на один результат.
- [ ] «Увімкни плейлист [назва]»: шукає в Моїй бібліотеці та відтворює.
- [ ] «Увімкни реп»: запускає трек, а не просто торкається кнопки відтворення списку.
- [ ] Українські команди з українськими, англійськими та російськими назвами працюють.

## Bolt на телефоні
- [ ] «Джарвіс таксі»: чекає повного завантаження Bolt.
- [ ] Якщо Bolt відкрито не з головного екрана, повертається на правильний екран.
- [ ] Натискає «Рушаймо», потім «Місце висадки».
- [ ] Вводить продиктовану адресу, натискає пошук/Enter і перший відповідний варіант адреси.
- [ ] Не підтверджує замовлення таксі без окремої команди користувача.

## Загальне
- [ ] Текст і голосові відповіді не зникають після виконання команд.
- [ ] Другу голосову команду можна подати після першої.
- [ ] Команди телефону з Watch7 виконуються на правильному пристрої.
- [ ] Під час слухання мікрофон працює реально, а не лише показує анімацію.
- [ ] Перевірити повідомлення про виконання дій внизу екрана.

Це **чекліст для фізичного тестування**, а не твердження, що всі ці сценарії пройдено на Pixel.
